# 单词工作台（wordsvideo）

管单词的软件和它的全部资料。以前分散在 ciyuanchaifeng 仓库里的总表、出题数据、维护技能、视频技能、本地出片和批量出片脚本，都搬到了这里，由软件统一处理。

现在能做的两件事：
1. **出题**：按总表顺序给每个词出 7 道题，网页镜像 AI（sorryios）写、程序体检、存进词库、记进度、上传。
2. **出片**：在这台电脑的 WSL 里用视频技能把单词做成构词动画视频，软件负责同步引擎、装环境、建批次、开工、看进度、登记视频。

以后要加的：把网上找的学习资料发给软件，自动提取、加工、分类（放在「词库/资料」）。

## 第一次用

1. 电脑上要有 Python（3.9 以上）和 Git；出片还要 WSL 里的 Ubuntu-24.04（以前本地出片装过的就能直接用）。
2. 双击 `启动.bat`。第一次会自动装 openpyxl 和 playwright，然后弹出软件窗口（http://127.0.0.1:8766）。
3. 「设置」里填 GitHub 令牌（fine-grained，只给 wordsvideo 仓库 Contents 读写；点「检测令牌」要显示“有写权限”），保存；第 1 步「选 AI」里填 sorryios 账号密码。
4. 软件会把仓库副本放进 `data\repo`，左下角显示“仓库 就绪”就能用了。

## 出题

「出题」页选“按总表顺序接着出”填个数，点「开始出题」。规矩和以前云端技能一样（规矩、范例从 `词库\总表视频细节数据\出题技能\zongbiao-questions.skill` 读，体检用 `工具\lianxi.py` 正本）。没过体检的词改 3 轮还不过就进「待人工」（在「出题」页里，点单词就地改稿），自动出题会跳过它们。「出题」页可以定时（每天几点出多少个），「设置 → 时间窗口」可以只在夜里干活。

## 做视频的六步、备选单词、手动接力

- 左边从上到下就是做视频的六步，一页只管一件事：①「选 AI」→②「检测」三样准备好了没 →③「选词」→④「出题」→⑤「画面」→⑥「出视频」。「选词」只管选词（「备选单词」勾上就是选上，软件记着；每个词都检测有没有题目、画面、视频，写明下一步；导入、自己输入的词先检测再加；「从总表里找」把还没有题目（或画面）的排在前面能选，已经有了的灰掉不能选）；「出题」「画面」给选上的词做，已经有的自动跳过、做完有汇报；「出视频」只收题目、画面都有的词，缺的列出来、点按钮去补，实时画面、每一步、排队和做完的任务都在那一步页面的下面（「这一步的进度」），不会跳到别的页；左边那一步旁边显示“在跑”或“要你操作”。「出题」里还有「规矩和时间」「记录」两个小标签。下面是「总览」（六步各自做到哪儿、选上的每个词走到哪一步、整张总表的方格图）、「成果」（渲染好的视频、能出视频的词、出好的题目）和「设置」（GitHub 仓库、软件版本）。
- 「出题」「画面」两页从上到下：这次给哪些词（选上的词，标着要出/要做、不重出）→ 这一步的进度 → 结果。出题结果：每个词的 7 道题；每个词出好题目就自动存一个 Excel 到成果文件夹的 `题目\<单词>.xlsx`，也能把选上的词合成一个 Excel。画面结果：每个词画面里的图；AI 做的自动拷到 `画面\<单词>\`，kit 里的点「画出来」在 WSL 里用视频技能画出来存进去。成果文件夹就是出片文件夹（默认 D:\构词视频），各处都有「打开文件夹」。没过的词、批量和定时、规矩和时间、记录在各自的小标签里。
- 「选词」页的「备选单词」：先把这一阵要做的词导进来存着（粘贴，或者从 Excel、txt、csv 读），每个词做到哪一步（还没做、缺画面、没做成、正在做、做好了）随时看得到；勾几个点「开始准备」，出题 → 画面 → 检查一条龙。只想单独出题、单独做画面，用「出题」「画面」两页（来源可以是备选单词，也可以按总表顺序）。只存在本机。
- 左边「选 AI」页点「手动接力」标签、右上角「改用这个」（比如用 zd87 上的 Claude）：在哪一步开始的，那一步的进度里会出现黄框，点「复制提示词」→ 到网页里粘贴发送 → 把整段回复粘回来、点「交回给软件」；检查、存盘、上传都自动。
- 不想点「复制」：「AI」页「手动接力」标签里打开“网页 AI 写完自己上传结果”，收件箱仓库就是中转仓库 Jacklee15333/files-transfer-and-receive（已经填好），收件箱令牌填「收件箱用」小令牌（只给中转仓库 Contents 读写），点「检测收件箱」。网页 AI 写完会自己把回复整理成 Excel（.xlsx：「题目」一题一行，「原文」给软件读）传进中转仓库的 inbox/，软件取走、检查、存进 wordsvideo，再把中转仓库里那个文件删掉。软件每 15 秒自己看一次中转仓库；黄框里「立即查看仓库」能马上看一次。黄框上面能直接改“每批几个词、每写完几个传一次”（下一批起按新的）。实时画面里的「打开网页 AI ↗」会用你平时的浏览器打开网页 AI。令牌会写进提示词，所以万能令牌不能填这里（填了软件会拦下）。
- 交接：「交接/wordsvideo-handoff.skill」发给新的 Claude 聊天，就能接着开发这个软件。

## 出片

进「⑥ 出视频」页，从上到下：

1. **出片前先检查**：一打开这一页就自动检查这台电脑——WSL、视频技能、出片脚本、总表、音节划分表、系统软件、声音模型、显卡（可选）、出片文件夹。没问题的打绿勾，有问题的打红叉，那一行后面就是修的按钮：「同步到 WSL」（把「引擎」里的脚本和视频技能、「词库」里的总表拷进 WSL）、「装系统软件」「装声音模型」「开显卡」。装的时候那一行转圈，装完自动再检查一遍。
2. **建批次**：第 3 步选上的、题目和画面都有的词列在这里，勾好、点「建批次」（批次名自动起好，也能改）。缺东西的单独列出来，点按钮去补。
3. **批次**：一批一行，后面四个按钮——开工（点了变灰，写“正在生成”）、暂停（马上停，进度都留着，按钮变「继续」）、停止（这一批不做了，做好的视频留着，出汇报；还能「接着做」）、删除（删批次的记录和日志，做好的视频不删）。点一行展开：现在在做哪几个词、做到哪一步、还要多久，电脑的 CPU、内存、显卡；卡住的词写着原因，旁边就是「看原因」「再试一次」「不做这个词」，点任何一个词也能弹出来处理。做完了展开就是任务汇报。卡在“准备”、起草检查说画面还要补的词合成一块「画面还要补」，点「交给 AI 补画面」：AI 照着“还要补什么”在上次的基础上改，补好一个，这一批就接着做一个。流水线在 WSL 后台做，软件关了也不停。
4. 做好的视频拷到 `D:\\构词视频\\<批次>\\`，自动登记进视频清单，列在这一页最下面「做好的视频」，点「播放」直接看。
5. 「总览」最下面的方格图选「看视频」，能看到哪些词有视频、哪些能出片、哪些还没有画面设置。

## 软件的版本、更新和改写

- 版本号在 `app/VERSION`，左下角能看到。GitHub 上有新版本时左下角会提示，到「设置」最下面点「更新到新版本」（或者在 GitHub Desktop 里 Pull），然后重开软件。
- 「设置 → 软件版本、更新和改写」：写清楚要改什么，网页 AI 改好后你先看改动，点「应用并发布」才会真的改。
- 每发布一个新版本，旧版本整个 app 文件夹先备份到「版本备份/v版本号/」，更新记录写在 `CHANGELOG.md`；不满意可以在「设置」最下面回退到任何一个备份。Claude 在仓库里直接改软件也照这个规矩。

## 现在的限制

- **视频画面要先做**：视频技能 kit 里只有 7A-U4 这 29 个词有画面设置，其余的词在「任务 → ② 做视频画面」里交给网页 AI 做。AI 做的画面质量要先挑几个词出片看看，满意了再大批做。
- **音节划分表没在仓库里**：读音拆分要用 `音节划分_总词库7869词_细分版.xlsx`，旧仓库里也找不到了。WSL 里以前装过的话照样能用；没有的话把它放进「词库」文件夹，再同步一次引擎。
- 视频不进 git（一个 20–45 MB，全表做完有几百 GB），只登记。
- 别和云端技能、chuti-helper 同时往词库里出题。旧仓库 ciyuanchaifeng 以后不再更新词库数据，以这里为准。
- 网页镜像 AI 的那部分（`app\web_model.py`）是超能小助里原样拷过来的；网站改版后，把修好的 `web_model.py` 拷过来覆盖就行。
