# 单词工作台（wordsvideo）

管单词的软件和它的全部资料。以前分散在 ciyuanchaifeng 仓库里的总表、出题数据、维护技能、视频技能、本地出片和批量出片脚本，都搬到了这里，由软件统一处理。

现在能做的两件事：
1. **出题**：按总表顺序给每个词出 7 道题，网页镜像 AI（sorryios）写、程序体检、存进词库、记进度、上传。
2. **出片**：在这台电脑的 WSL 里用视频技能把单词做成构词动画视频，软件负责同步引擎、装环境、建批次、开工、看进度、登记视频。

以后要加的：把网上找的学习资料发给软件，自动提取、加工、分类（放在「词库/资料」）。

## 第一次用

1. 电脑上要有 Python（3.9 以上）和 Git；出片还要 WSL 里的 Ubuntu-24.04（以前本地出片装过的就能直接用）。
2. 双击 `启动.bat`。第一次会自动装 openpyxl 和 playwright，然后弹出软件窗口（http://127.0.0.1:8766）。
3. 「设置」里填：GitHub 令牌（fine-grained，只给 wordsvideo 仓库 Contents 读写；点「检测令牌」要显示“有写权限”）、sorryios 账号密码。保存。
4. 软件会把仓库副本放进 `data\repo`，左下角显示“仓库 就绪”就能用了。

## 出题

总览里填个数，点「加入队列」。规矩和以前云端技能一样（规矩、范例从 `词库\总表视频细节数据\出题技能\zongbiao-questions.skill` 读，体检用 `工具\lianxi.py` 正本）。没过体检的词改 3 轮还不过就进「待人工」，自动出题会跳过它们。「任务」页可以定时（每天几点出多少个），「设置 → 时间窗口」可以只在夜里干活。

## 做视频的五步、备选单词、手动接力

- 左边从上到下就是做视频的五步，一页只管一件事：①「检测」三样准备好了没 →②「选词」→③「出题」→④「画面」→⑤「出视频」；点了开始以后都到「正在做」看实时画面和每一步。
- 「选词」页的「备选单词」：先把这一阵要做的词导进来存着（粘贴，或者从 Excel、txt、csv 读），每个词做到哪一步（还没做、缺画面、没做成、正在做、做好了）随时看得到；勾几个点「开始准备」，出题 → 画面 → 检查一条龙。只想单独出题、单独做画面，用「出题」「画面」两页（来源可以是备选单词，也可以按总表顺序）。只存在本机。
- 左边「AI」页点「手动接力」标签、右上角「改用这个」（比如用 zd87 上的 Claude）：「正在做」页会出现黄框，点「复制提示词」→ 到网页里粘贴发送 → 把整段回复粘回来、点「交回给软件」；检查、存盘、上传都自动。
- 不想点「复制」：「AI」页「手动接力」标签里打开“网页 AI 写完自己上传结果”，收件箱仓库就是中转仓库 Jacklee15333/files-transfer-and-receive（已经填好），收件箱令牌填「收件箱用」小令牌（只给中转仓库 Contents 读写），点「检测收件箱」。网页 AI 写完会自己把回复整理成 Excel（.xlsx：「题目」一题一行，「原文」给软件读）传进中转仓库的 inbox/，软件取走、检查、存进 wordsvideo，再把中转仓库里那个文件删掉。实时画面里的「打开网页 AI ↗」会用你平时的浏览器打开网页 AI。令牌会写进提示词，所以万能令牌不能填这里（填了软件会拦下）。
- 交接：「交接/wordsvideo-handoff.skill」发给新的 Claude 聊天，就能接着开发这个软件。

## 出片

进「视频」页：

1. **把引擎同步进 WSL**：把「引擎」里的脚本和视频技能、「词库」里的总表拷进 WSL（代替以前的 `02_get_repo.sh`，不再从 ciyuanchaifeng 取）。
2. 第一次用这台电脑出片：依次点 ① 装系统软件、② 装声音模型（③ 开显卡可选），每一步点「看」到最后一行是 ✅ 再做下一步。以前已经装好的直接跳到第 3 步。
3. **建批次**：勾选词、起个批次名。现在只有画面设置做好的词能出片。
4. **开工**：批次后面点「开工」。流水线在 WSL 后台做，软件关了也不停；点「进度」看，做好的视频拷到 `D:\构词视频\<批次>\`，自动登记进视频清单。卡住的词在「处理某个词」那里看日志、重做或跳过。
5. 总览的方格图选「看视频」，能看到哪些词有视频、哪些能出片、哪些还没有画面设置。

## 软件的版本、更新和改写

- 版本号在 `app/VERSION`，左下角能看到。GitHub 上有新版本时左下角会提示，到「设置」最下面点「更新到新版本」（或者在 GitHub Desktop 里 Pull），然后重开软件。
- 「设置 → 软件版本、更新和改写」：写清楚要改什么，网页 AI 改好后你先看改动，点「应用并发布」才会真的改。
- 每发布一个新版本，旧版本整个 app 文件夹先备份到「版本备份/v版本号/」，更新记录写在 `CHANGELOG.md`；不满意可以在「设置」最下面回退到任何一个备份。Claude 在仓库里直接改软件也照这个规矩。

## 现在的限制

- **视频画面要先做**：视频技能 kit 里只有 7A-U4 这 29 个词有画面设置，其余的词在「任务 → ② 做视频画面」里交给网页 AI 做。AI 做的画面质量要先挑几个词出片看看，满意了再大批做。
- **音节划分表没在仓库里**：读音拆分要用 `音节划分_总词库7869词_细分版.xlsx`，旧仓库里也找不到了。WSL 里以前装过的话照样能用；没有的话把它放进「词库」文件夹，再同步一次引擎。
- 视频不进 git（一个 20–45 MB，全表做完有几百 GB），只登记。
- 别和云端技能、chuti-helper 同时往词库里出题。旧仓库 ciyuanchaifeng 以后不再更新词库数据，以这里为准。
- 网页镜像 AI 的那部分（`app\web_model.py`）是超能小助里原样拷过来的；网站改版后，把修好的 `web_model.py` 拷过来覆盖就行。
