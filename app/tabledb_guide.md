# 总表拆分说明（发给 AI 用）

你在帮一位中学英语老师整理一张英语单词的“词源拆分总表”。这张表以前把很多内容挤在一个单元格里，现在要按列拆开，放进老师的软件“单词工作台”。
**这次只拆、不写**：原表里的话搬到对的列里，一个字都不改、不加、不删；拿不准放哪一列的，原样放进「没放进去的」。

## 你会拿到的文件

1. **要拆的表**（软件导出的，文件名像「总表要拆的-第1到3批-196行.xlsx」）：一行一个词。
   - 灰色、绿色表头的列（基本信息、考点、演变、同义词组……）**软件已经填好了，不要动**。
   - **黄色表头的列是你要填的**（下面第三节）。
   - 最右边几列「【原表】前缀」「【原表】词根」「【原表】单词部分」「【原表】后缀」「【原表】辨析」……是原表那一格的原话，你对着它拆。
2. **总表导入模板.xlsx**：第一页「拆分结果」里 make、rematch、popular 三行是拆好的样子；第二页「列说明」写了每一列放什么、谁来填。

## 交回什么

- 交回**同一个文件**：表头、行数、行的顺序、单词、批次、序号都不变；只把黄色那几列填上。
- 一份太长写不下，可以分几份交（比如 50 行一份），文件名后面加 -1、-2。每一份都要带着表头和单词、批次、序号这三列。
- 交回 .xlsx。不能生成文件的话，把这几列写成表格（单词、批次、序号 + 黄色的列），老师自己粘进去。

## 黄色的列：怎么拆

### 词根词缀卡：每一部分（部分1～部分4）

「拆分」写着这个词拆成几部分（re + match、popul + ar、ex + plore）。按顺序，第一部分填进「部分1 …」，第二部分填进「部分2 …」。拆分是 — 或者没有 + 的（make、match ≈ make），这几列都空着（那种词的说明软件已经放进「来历」）。

每一部分的原话在「【原表】前缀 / 词根 / 单词部分 / 后缀」里，形如：

> re-：身份：“再、又”（来自拉丁语前缀 re-，本义“往回”，往回再来一次就是“再”；只用在词前，不单独成词；同 rewrite 重写、replay 重放）

拆成：

| 列 | 放什么 | 例（re-） |
|---|---|---|
| 部分N | 写法：前缀带后面的 -，后缀带前面的 -，词根带后面的 -，单词原样 | re- |
| 部分N 身份 | 前缀 / 词根 / 后缀 / 单词（看它在原表哪一列；「单词部分」那一列就是“单词”） | 前缀 |
| 部分N 来源 | 原话里写了“来自拉丁语 / 希腊语 / 法语 / 英语本族……”才填，没写就空着 | 拉丁语 |
| 部分N 意思 | 身份后面那个意思，短：引号里的那几个字 | 再、又 |
| 部分N 记法 | 原话里“记：”后面那一句（到下一个“音变：”“辨析：”之前），去掉“记：”两个字 | （re- 没有） |
| 部分N 音变 | 原话里“音变：”后面那一句，去掉“音变：” | （re- 没有） |
| 部分N 补充 | 别的说明：本义、出处、“只用在词前”、“同 rewrite 重写” 这类，原话照搬，用；隔开 | 本义“往回”，往回再来一次就是“再”；只用在词前，不单独成词；同 rewrite 重写、replay 重放 |

- 一句话里同时有来源和补充的（“来自拉丁语前缀 re-，本义‘往回’”）：来源填“拉丁语”，补充里不用再写“来自拉丁语前缀 re-”，从“本义”开始写。
- 「单词部分」那一列的形如“match：比赛（见 match）”：部分N 写 match，身份写“单词”，意思写“比赛”，补充写“见 match”。

### 词缀辨析、为什么用这个词缀

前缀、后缀那一格后面常有两段：

- “辨析：同样是把名词变成形容词：-ful ……”——从“同样是”开始到这一段结束，整段放进「**词缀辨析**」（去掉“辨析：”三个字）。
- “为什么用 -ar 不用 -al：……”——这一句整句放进「**为什么用这个词缀**」。

这两段不要再放进部分N 补充。

### 同义词辨析：区别

「【原表】辨析」里，【同义词】那几行软件已经拆好了（「同义词组」），剩下的话软件放在「辨析说明」。
你要做的是从剩下的话里，**把每个词自己的那一句区别拆出来**，放进「**区别**」：一行一个词，写成 `词｜区别`，区别用原话：

> make 重“造出东西、产生结果”（make a cake / a mistake / a decision）；do 重“从事一项活动”（do homework / do the dishes）

拆成：

```
make｜重“造出东西、产生结果”（make a cake / a mistake / a decision）
do｜重“从事一项活动”（do homework / do the dishes）
```

- 原话里没有分别讲每个词的（只有一句总的说明），「区别」空着。
- 只拆原话，不要自己补写别的词的区别。

### 没放进去的

拆完对一遍：「【原表】…」那几格里的每一句话，都要能在某一列里找到（软件导入时会自己对，找不到的会标出来让老师看）。实在不知道放哪一列的，原样放进「**没放进去的**」。

## 不要做的

- 不要改字、不要改标点、不要翻译、不要润色、不要补写原表没有的内容。
- 不要动已经填好的列（灰色、绿色表头），不要删行、加行、调换顺序。
- 「例句」这一次空着（以后单独补）。

## 交之前自己对一遍

1. 行数、顺序、单词、批次、序号和拿到的文件一样
2. 拆分有几部分，就填了几个「部分N」，写法、身份、意思都有
3. 原话里的“记：”“音变：”“辨析：”“为什么用”都放进了对的列
4. 原表的每一句话都能找到；放不进去的在「没放进去的」
