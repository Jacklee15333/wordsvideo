> 合成词里两个词谁在前、谁在后，连字符怎么用，不是用词规律，见 `scripts/hecheng_catalog.py`（「合成规律一览」）和 writing_guide.md 第 11 节。

> **清爽格式（2026-11 起）**：用词规律写在组合列（M），不编号：用到规律的那一步下面紧接一行 `　用词规律：规律（本词：原来的意思 → 新意思；一个熟悉的例子）`；一步用到两条就写两行；同一条规律再用到时，那一行只留熟悉的例子。步骤末尾不再标〔用词规律①〕。下文说的“意思怎么变 / 用词规律①②”两行、编号，都是脚本内部的旧写法（columns.parse_I 读表时会按出现顺序编号、标回步骤），写回表里时自动变成清爽格式。

> **2026-11 用词规律轮（用户定下，最要紧）**：用词规律要讲**真正的规律**——说得出“意思是怎么来的”，学生拿它能猜别的词。
> 用户看 camera 那一行“一个词用进某一行（电脑、法律、体育、音乐……），就有了那一行的专门意思（camera 照相机 → 摄像机；mouse 老鼠 → 鼠标）”：
> “这个解释就显得多余……讲解了感觉像没有讲解一下”。这类话只说了“有了专门意思”，没说怎么来的。所以：
> 1. **两条空洞的说法取消**：“一个词用进某一行…”（原 571 行）、“同一个词，英国、美国的用法有时不一样”（原 290 行）。
>    “（计算机）（英）”这类标签照旧写在那一步的结果里（那是事实），但不再当规律写；也不再按标签自动标。
> 2. 这 861 行逐条看过，换成真规律：核心意思不变换了对象（362）、作用像（77）、样子像（26）、越用越窄（42）、越用越宽（17）、
>    性质 → 有这种性质的东西（16）、东西换了代旧名字接着用（9）、做事的人 → 做事的东西（11）……；**找不到真规律的 269 条，规律那一行删掉**（步骤本身已经讲清了）。
> 3. **别的规律也要对得上前提**：“表示动作的词…”只给真的动作词。leg“用来站立、走路的肢体”被标成“动作 → 做这件事用的东西”这类，复核后删了 226 条（211 个词）、改贴 60 条
>    （safe 安全的 → 保险箱：改成“表示性质、状态的词…”）。
> 4. 熟悉的例子要和本词是同一回事：camera 配 phone 电话 → 手机，不配 mouse 老鼠 → 鼠标。
> 5. 怎么选：先问“新意思和老意思是不是同一个核心动作 / 样子，只是对象换了”——是，用“核心意思不变”；不是一类东西、只是像——样子像用“样子、形状像什么…”，
>    作用像用“作用、做法像什么…”；大类里专指一种用“越用越窄”；老东西被新东西顶替、名字照用用“东西换了代…”；都不是就不标。
> 体检：`scripts/rule_check.py`（G 类应为 0）、`scripts/tonggen_check.py` 的 old_rule（应为 0）。逐条判断的记录在 `scripts/archive/tonggen/`。

# 用词规律目录（一词多义是怎么来的）

这份目录和 `scripts/sense_rules.py` 里的 `EX`（规律和例子）、`WHY`（为什么）、`RULES`（怎么认）一一对应；要加新规律，三处一起加，例子必须是总表里的词。
总表里每条规律用到了哪些词，见「用词规律一览」工作表（每次跑 `sense_write.py` 按全表重算）。

标规律要保守：宁可不标，不要标错。**规律开头说的是什么词，这个词就得是什么词**：“表示动作的词……”只给动作（动词、-ion/-ing/-ment 这类动作名词）；这个词本身是“做…的人”时，指机器、东西用“表示‘做这件事的人’的词……”；形容词当名词用（private 私人的 → 列兵）用“表示性质、状态的词……”；本来就是名词的不算“动作直接当名词用”，本来就是动词的不算“东西、性质直接当动词用”。改完跑 `scripts/rule_check.py` 核对。自动标是按组合列 → 那一行的“说明”和“结果”里的说法认的，再加了几条词性检查（本来就是动词的，不算“名词当动词”；结果是“…的”的，不算“做出来的东西”；“被…了的”形式当形容词，是语法，不算规律）。

## 写进总表的样子

各部分解释里，一词多义的词加两行（行首是中文标签，不算“部分”，不影响 audit 的 [5] 和视频卡片配对）：

```
意思怎么变：从字面的“传达这件事”出发：① 一条消息从这个人“分”到那个人，再到更多人 → 交流、沟通；传达 ② 传过去的那样东西 →（传递的）信息、消息〔用词规律①〕 ③ 用来把消息传来传去的电报、电话、网络 →（复数）通信手段、通信系统〔用词规律②③〕
用词规律：① 表示动作的词，也拿来叫这个动作做出来、留下来的东西（communication 交流、沟通 → 信息、消息；invention 发明 → 发明物） ② 名词用复数时，常常专指一类东西、一整套或一大片（communications 通信手段、通信系统；waters 水域） ③ 表示动作的词，也拿来叫做这件事用的东西（communication 交流、沟通 → 通信手段、通信系统；transport 运 → 运输工具）
```

- 意思怎么变：照组合列 → 那几行写，“结果”原样照抄（视频技能按结果对上演变链那一步）；只给今义有两个以上意思、→ 行有两行以上的词写。
- 用词规律：每条“规律（本词：原来的意思 → 新意思；一个熟悉的例子）”，最后一对括号里是例子。规律本身可以带括号（如“某一行（电脑、法律……）”）。
- 〔用词规律①②〕标在用到规律的那一步后面，编号和“用词规律”那一行对应。
- 例子（最后一对括号）里不要再写①②：视频按括号外的①②切开规律（tap、fan、peep 因此读乱过）。两个同形词的，写“tap 酒桶上的出酒龙头 → 水龙头”，不写“tap ① …”。
- 只标真用到的规律：fan 的“粉丝”是 fanatic 截短来的，不是“用进某一行”；截短、同形词这类不在目录里的，不标。
