# 写法口径（改解释、补内容时照这个写）

**三列分工**：前缀、词根、单词部分、后缀四列（以前的各部分解释）只讲各部分；下面第 2、3 节说的“在这里”一段，写在组合列等式下面一行，只讲重点：`词性变化（-ion）：动词 → 名词。communicate“传达”加上 -ion（…这件事），就成了“传达这件事”`——词性、后缀本身的意思（括号里）、合起来成了什么，三样都要有；不写“名词前面能加 the、my”“形容词说的是‘什么样的’”这类讲语法的套话（第 2、3 节模板里的这些话是旧写法，生成后由 columns.py 自动精简）；步骤已经讲到的意思不再在末尾写“所以 W 指 A / B”；后缀列的后缀行只写作用、来源和别的说明。“意思怎么变”不再单写一行，组合列 → 行里用到规律的那一步末尾标〔用词规律①〕，紧接着下一行写 `　用词规律①：规律（例子）`。【演变】和步骤讲同一回事的，年代写进步骤。

## 1. 组合列第一行：【构词逻辑】等式

视频的“合起来”一幕读这一行等号后面的引号：“合起来，就是……”。所以每个有拆分的词，第一行都要有等式：

- 两部分：`【构词逻辑】trans（到另一边）+ port（搬运）=“搬到另一边”`
- 几条路：字面意思用“ / ”隔开（配音念成“或”），后面接说明：`【构词逻辑】live（活、生存）+ ing（…这件事；正在…的）=“过日子这件事 / 正活着的”，有两条路：`
- 不写派生路线（2026-11 起）：母词 + 后缀写成组合公式 `【构词逻辑】communicate（传达、交流）+ or（做…的人或东西）=“传达、交流的人”`；前缀词写成 `【构词逻辑】un（不）+ used（用过的；习惯的）=“没用过的 / 不习惯的”`，引出下文的“跟着 used 的两个意思也分两条：”单独成下一行。只有截短、缩写、变体这类写不出组合公式的，才写 `派生路线：apply（用上）→ application（应用；应用程序）→ app`
- 括号里的“=”不算等号：`a（= on）+ wake（醒）=“醒起来”` 没问题。
- 两种拆法（stalk、Georgian）：两个等式用“；”隔开，第一个对应主拆法。

下面 → 开头的行写意思一步步怎么变（“说明 → 结果”）；分几条线的可以用 ①② 开头（“① 动词：…… → 活、生存”），下面再接 → 行。每个词都要有含义，写在 F 列「含义」（2026-11 从组合列的【今义】挪出来）：同一词性的意思写一行，行首写词性；例子写在 G 列「例句」（见第 7 节）。

## 2. 后缀行的写法

格式：`-ion：作用（来源；同 例词）；在这里：动词 → 名词。……所以 vision 指视力 / 愿景、构想 / 远见；其他说明`

- **作用**：加在什么词后面、变成什么词（“一般加在动词后面，变成名词”）。
- **来源**：这个后缀的母词。英语本族的写“英语本来就有的后缀，古英语写作 -ere”；外来的写“来自拉丁语名词词尾 -io，经法语进入英语”。“经……”是路过的语言，不算来源。说法和构词动画技能卡片上的“来自拉丁语 / 英语本族”一致（视频技能会直接读这个括号）。-able 和单词 able 不是一个来源，要写明；-ly 来自古英语 lic，和 like 是一家，写“见 like”。
- **在这里**：讲词性，学生才知道意思为什么会变。四种词各一句固定说法：
  - 动词说的是“做什么”，是一个动作；
  - 名词说的是“什么东西”，前面能加 the、my，能当主语、宾语；
  - 形容词说的是“什么样的”，放在名词前面或 be 后面；
  - 副词说的是“怎样做的、做到什么程度”，修饰动词、形容词。
  然后说：原来是什么词 → 加上后缀变成什么词 → 所以有了哪几个意思。不要写“‘看’这件事”这种学生看不懂的话。

各类后缀的说法（`sense_rules.py` 的 `pos_sentence`）：

| 变化 | 后缀 | 在这里怎么说 |
|---|---|---|
| 动词 → 名词 | -ion、-ment、-ance、-ure、-age、-al（名词）、-ing（名词）…… | X 是一个动作，加上 -ion，就把这个动作当成一样东西来说。一个动作当成东西，可以是这件事本身、做出来的结果、做它的本事或用的东西，所以 W 指…… |
| 动词 → 人或东西 | -er、-or、-ee | 就成了“做这个动作的人或东西”；-ee 是“被……的那个人” |
| 名词 → 人 | -ist、-ian | 就成了“做这件事、搞这一行的人” |
| 动词 → 形容词 | -able、-ive、-ing、-ed、-ent | 说一样东西“能被……”“会……”“正在……”“已经被……了” |
| 名词 → 形容词 | -al、-ic、-ous、-ful、-less、-y、-ish | 说的是“和……有关的”“充满……的”“没有……的”这种性质 |
| 形容词 → 名词 | -ness、-ity、-cy | 就把这种性质当成一样东西来说 |
| 形容词 → 副词 | -ly | 转过来说动作“是怎样做的、做到什么程度” |
| 变成动词 | -ize、-ify、-en、-ate | 就把“……”变成一个动作 |
| 名词 → 名词 | -ship、-hood、-dom、-ism | 指身份、关系、状态、主张 |
| 名词词尾 -y | allergy、discovery 里的 -y（拉丁语 -ia） | 说的是一件事、一种情况，加上 -y 成了说这种状态的名词（不要当成形容词后缀 -y） |

两种要特别处理的情况：

- **母词的意思有好几个，本词用的是后面那个**：先讲本义怎么变成那个意思，再用它讲。例：“communicate 本义‘使共有’：把自己知道的、拥有的‘分’给别人，让它变成彼此共有的，消息就这样传开了，就成了‘传达’。‘传达’是一个动作，加上 -ion……”。过渡的道理取母词那一行组合列里、结果写着这个意思的那一条 →；找不到就不跳，照原来的意思讲（`bridge`）。
- **三部分以上的词**：“ex + ped + it 合起来是‘把脚从镣铐里解出来’，是一个动作，加上 -ion……”。引号里取构词逻辑等号后面第一对引号；没有就写“ex + ped + it 合起来是一个动作”。

“在这里：”这一段里不用“；”（视频技能按“；”切开读），几个意思之间用“ / ”。

## 3. “在这里”不能出现的写法（视频会念出来）

视频配音读“在这里”里“加上 -xx”后面、“，所以”前面那一段（括号里的不念）。下面这些都会原样念出来，sense_write.py 已经避开，手写时也别写：

| 不要写 | 改成 |
|---|---|
| 引号里填“它”：说一样东西“正在它”、“和它有关的”、“能被它” | 用构词逻辑的字面意思：说一样东西“正在把东西搬进来的” |
| “的的”：当艰难的的身份 | 前面本是形容词的，改说“形容词 → 名词。hard“艰难的”说的是“什么样的”，是一种性质，加上 -ship……指“艰难的状态”” |
| “有日样子的”“有像样子的”（名词 + -ly） | 用字面意思：说的是“每天的”这种性质 |
| “使变得力量”（名词 + -en） | 名词 → 动词，意思是“使有力量” |
| -ate 的“加上它” | people“人”加上 -ate，就成了一个动作 |
| 引号里夹“；”：organize“组织；整理” | 改成“、”：organize“组织、整理” |
| 词性说错（handful 当形容词、expertise 当动词、destiny 的 -y 当形容词词尾） | 按这个词实际的词性写：名词 → 名词，指“满满一手的量” |

模板套不上的后缀（少见后缀、母词意思取不到、复数、比较级、过去分词……）用通用写法，sense_write.py 会自动这样写：

`在这里：{词性变化}。{前面部分}“{意思}”加上 -xx（{后缀的意思}），合起来是“{构词逻辑的字面意思}”，所以 W 是 / 指 {今义}`
例：`在这里：变成名词。weigh“称”加上 -t（称出来的结果），合起来是“称出来的量”，所以 weight 指重量 / 体重 / 砝码、重物`

词性变化定不了时脚本会先写“合起来看”，要逐句改成具体的词性（名词用“指”，其他用“是”）。-it-、-at-、-un- 这类夹在中间的成分不写“在这里”。

前缀行也写来源，进括号：`mis-：“错、坏”（英语本来就有的前缀，古英语 mis-；同 mistake 错误）`；a-、e-、an- 按这一行的来历写（= on 是英语本族、= ad- 是拉丁语、e-book 的 e- 是 electronic 的首字母）。

前面那部分本身是形容词（“…的”）、后缀不改词性时，写“形容词 → 形容词。classic“头等的”本身说的就是“什么样的”，加上 -al 还是形容词……”。

## 4. 【背景】的写法

只写在每组第一个词上。先说来源语言和年代（“这是英语自己的词，古英语里写作 macian”），再讲当时的生活、这个词最早是怎么用的，最后点出和本组几个词的关系（“同一个 *mag- 还有‘使合适’的意思，所以 match 和 make 是一家”）。拿不准的写“词典推测 / 也许”。没有来历可讲、好懂的词写“—”。

## 5. 视频读表的坑（wordfilm.js 2.3）
6. 清爽格式
7. 含义列（F）、例句列（G）的写法

- 视频只认以【构词逻辑】开头的那一格是组合列；前缀、词根、后缀列里写“见本条【构词逻辑】”这类方括号会出问题，写成“见本条构词逻辑”。
- 拆分按括号外的“ + ”切；括号里不要写“+”（surg(=chirurg) + ery，不写 surg(=chir 手 + urg 工作)）。
- 部分和解释行的配对：先认写法一样的，再认头尾对得上的；单个字母按“字母 + 括号里省掉的字母”配（n(e) → ne）；双写字母（plan + n + ed）自动并进前一部分。标签和拆分对不上时，后面的部分会配错行。
- 后缀来源：括号里写“来自…”“英语本来就有…”最稳；写在正文里的（“它来自古英语 lic”）视频也能读，但口径要求进括号。
- 用词规律：只在括号外的①②处切开，例子（最后一对括号）里不要再写①②。
- 今义开头的①②（两个同形词）视频会去掉，不影响。

## 6. 清爽格式（2026-11 起，优先于上面各节里的旧写法）

上面第 1–3 节写的“词性变化（-ion）：……加上 -ion，就成了……”“〔用词规律①〕”“　用词规律①：”是旧写法，脚本内部还按它生成，`compose_I` 写回表里时自动变成下面的样子：

```
【构词逻辑】communicate（使共有、传达）+ ion（…这件事）=“传达这件事”；词性变化（-ion）：动词 → 名词
→ 一条消息从这个人“分”到那个人 → 交流、沟通；传达
→ 传过去的那样东西 →（传递的）信息、消息
　用词规律：表示动作的词，也拿来叫这个动作做出来、留下来的东西（communication 交流、沟通 → 信息、消息；invention 发明 → 发明物）
```

- 第一行末尾接“；词性变化（-xx）：A → B”；几个后缀：“（-less、-ly）：名词 → 形容词 → 副词”；接不成一条的：“（-ic）：名词 → 形容词；（-s）：名词 → 名词（复数）”；没变词性的写“词性不变”（against 的 -t）。
- 后缀等式 `前面部分“意思”+ -xx（后缀本身的意思）=“合起来的意思”`：第一行没有的本义、外语里的几个后缀（dictionary）才单写；单后缀、第一行已经是等式的不写。英语里几个后缀的词用直接母词（thoughtlessly = thoughtless + ly，见 thoughtless），只剩一个后缀；外语里的几个后缀，前一个等式的结果就是后一个的前面部分。
- 第一行末尾的“，有两条路：”“跟着 X 的两个意思分两条：”单独成一行，放在后缀等式下面、步骤上面。
- 用词规律：不编号，紧跟在用到它的那一步下面；同一条再用到时只留熟悉的例子。
- 后缀行的来源一律进括号：`-ture：表示“将要…的”的词尾（来自拉丁语 -turus）；futurus 就是“将要是的”`，不写成“拉丁语表示“将要…的”的词尾（-turus）”；`-ly：……（来自古英语 lic“身形”，和 like 同源，见 like；同 quickly 快速地）`，不写成“；它本身来自古英语 lic…”。
- 视频读清爽格式的办法见 SKILL.md“视频技能怎么读清爽格式”。

## 7. 含义列（F）、例句列（G）的写法（2026-11 例句分列轮起）

含义（F）：
```
n. 比赛；对手；相配的人或物
v. 相配、匹配；比得上
v. ① 轻拍、轻敲；（触屏）轻点
n. 踢踏舞
n. ② （英）水龙头
phr. carry out 执行；carry on 继续
modal v. （转述）将会；（虚拟）就会；（礼貌请求）能否…、愿意…吗
```
例句（G）：
```
比赛：a football match
对手：meet one's match 遇到劲敌
轻拍、轻敲：tap on the door；tap sb on the shoulder
能否…、愿意…吗：Would you mind…?
```

- 含义行首：词性缩写 + 一个空格。词性只用 n. / v. / modal v. / aux. v. / adj. / adv. / pron. / prep. / conj. / num. / art. / int. / phr.（`scripts/meaning.py` 的 POS）。同一词性只写一行，意思之间用“；”。
- 标签（英、美、口、喻、贬、书面、计算机、复数、过去式……）写在意思前面的括号里；同形词的 ①② 写在词性后面，第二个词从“② …”那一行起。
- 含义里不写例子：括号里只留中文说明（尤指…、复数 X、英式拼写，同 X、1910 年已见）。英文开头的例句、例词、搭配写到例句列。
- 例句一行一个意思：“意思：例子；例子”。“意思”照抄含义里那个意思、去掉括号；和别的意思重了就带上标签（（数量、程度）高的），还重就在前面加词性（n. 聊天、闲谈）。例子里可以带中文翻译和小注（a two-storey house 两层小楼）。
- 不写进含义列的：派生词、合成词（写 O 列【派生】【合成】）；“复数 X”“也写 X”“反义 X”这类说明（并进那个意思的括号）；只写“同 X”的（要写意思，再在括号里注“英式拼写，同 X”）；写成英文句子的意思（改成中文意思，句子写到例句列）。
- 以“=”开头的写成“（= X）意思”，行首有词性，不会被 Excel 当成公式。
- 英式、美式写法不同的词（2026-11 英美写法轮，project_rules.md 第 51 条），第一行末尾写一处：`adj. 色彩鲜艳的；丰富多彩的（英式拼写，美式写作 colorful）`、`n. 化妆品、妆容；构成；性格、素质（美式写法，英式多写作 make-up）`；字母不同用“拼写”，连字符、连写、分开写不同用“写法”；英美一样的不标。名单在 scripts/yingmei_data.py，写完跑 yingmei_check.py。
- 视频怎么读：wordfilm.js 的 `fromPosLines(含义, 例句)` 把两列合起来还原成“（n.）比赛（a football match）；（v.）相配”再读：开头那句用含义第一行的第一个意思，每个意思的例句从例句列对上；phr. 的条目不当成单独的意思画画。

## 8. 前缀、词根、单词部分、后缀四列（J、K、L、M）的写法（2026-11 分三列轮起；同月单词列轮加了 L 列）

以前的“各部分解释”一格拆成四列，每列一种部分，每部分一行“标签：解释”，没有的写“-”：

| 列 | 写什么 | 例子 |
|---|---|---|
| J 前缀 | 标签以 - 结尾的前缀 | `re-：“再、又”（拉丁语前缀 re-…；同 rewrite 重写）` |
| K 词根 | 不能单独用的词根（拉丁、希腊词根，bio、geo 这类构词成分，外语里的成分，古英语里今天不单用的成分），加连字符；连接成分、双写的字母 | `-spect：看（拉丁语 specere）`、`tsu-：日语“津”`、`-i-：连接用的元音` |
| L 单词部分 | 能单独用的英语单词，不加连字符：基础词本身、母词、合成词里的各个词、专有名词、缩写字母代表的词；复数、过去式这些形式也算 | `make：英语本族的基础词…`、`match：比赛（见 match）`、`up：最基本的意思是“向上”…`、`hands：双手（hand 的复数）` |
| M 后缀 | 标签以 - 开头的后缀，中间的成分（-it-、-at-） | `-ing：①“正在…的”…（英语本来就有…）` |

- 怎么分：make（基础词）整格写在单词部分，词根列写“-”；make-up（合成词）的 make、up 都写在单词部分；rematch、matching（词缀 + 单词）的 re-、-ing 写在前缀、后缀列，match 写在单词部分；transport 的 -port 是拉丁词根，写在词根列；yesterday 两样都有：yester- 在词根列、day 在单词部分。

## 10 动词的过去式、过去分词（2026-11，project_rules.md 第 47 条）

组合列（模板在 scripts/archive/dongci/vhelp.py）：

```
【构词逻辑】write（写）→ written =“被写下来的”
① 过去分词：有“完成”“被动”两层意思——跟在 have 后面是“已经写了”，跟在 be 后面是“被写” → 已经写了；被写
→ 过去分词放在名词前、be 后面当形容词，就是“被写了的”：用文字写下来 → 书面的（a written test 笔试；和 spoken 口头的相对）
【语法】write – wrote – written：written 是过去分词，跟在 have、be 后面，或当形容词（I have written two letters. / It was written in 1850.）
```

- 过去式写“说这件事在过去发生、已经结束了 → 写了”；两样都是的（made、kept）先写 ① 过去式、再写 ② 过去分词。
- “被…”要说得通：被说、被找到、被卷走可以；说不通的（got、begun、met、fought）改写成合适的说法（“跟在 be 后面，多说需要、要求被满足”），不硬套模板。不及物动词用“已经…了”的说法。

音变列：

```
【字母变化】wrat（古英语）→ wroot（中古英语）→ wrote（英语）
① 古英语 wrītan“刻、划、写”是强变化动词，不加 -ed，靠换元音表示时态：wrītan – wrāt – writen；过去式 wrāt 的 ā 是长音。
② 中古英语里长音 ā 变成长音 o，常双写成 oo：wrat → wroot（同 stān → stone、bān → bone、hām → home）。
③ 后来改用“o + 辅音 + 不发音的 e”表示长音 o：wroot → wrote；后来英语的长元音整体变了读法（元音大推移），读 /rəʊt/。
```

## 13 接在拉丁语过去分词词干上的词（2026-11 过去分词轮，project_rules.md 第 54 条）

整个从拉丁语借来的名词、形容词，-ion（拉丁语 -io）、-ive（-ivus）、-or、-ory（-orius / -orium）、-ure（-ura）不接在动词原形上，而是接在过去分词（“被…了的”形式）的词干上。拆分写词干、括号里写母词，后面几列各讲各的：

```
拆分：competit(=compete) + ion
词根：competit-：compete（竞争、比赛）的过去分词词干：拉丁语 competere“一起争取”→ 过去分词 competitus → 词干 competit-（见 compete）
后缀：-ion：把动作变成名词：“…这件事”或“…的结果”（来自拉丁语名词词尾 -io，经法语进入英语；同 action 行动、invention 发明）；接在动词的过去分词词干后面，不接在原形上：competit- 加 -ion → competition
组合：【构词逻辑】competit（竞争、比赛）+ ion（这件事）=“一起争取”这件事；词性变化（-ion）：动词 → 名词
　　　　构词：competition 不是英语自己用 compete 加 -ion 造出来的，而是整个从拉丁语 competitio 借来的。拉丁语造“…这件事”的 -io 名词，不接在动词原形上，而是接在过去分词（“被…了的”形式）后面：competere（一起争取）→ 过去分词 competitus → 词干 competit- → competitio
```

- **先查来历**（etymonline）：“from Latin …ionem / …ivus / …orius / …ura”→ 整个借来的，照上面写；“from Latin X-, past-participle stem of … + -ive / -ory”→ 英语照拉丁规矩造的，拆分一样写，构词行写“X 是英语后来照拉丁语的规矩造的：-ive 不接在动词原形上，而是接在过去分词（“被…了的”形式）后面：链 → 本词”；“noun of action from X (v.)”“from French …”→ 后来自己用现成 -ation 造的，拆分照旧（transport + ation），构词行写“transportation 是英语后来自己造的词（1530 年代）：-ation 是从 information 这类拉丁词里借来的现成后缀（at 本来是拉丁语过去分词的标志），英语把它当成一个整体，直接加在 transport 后面”，词加进 guoqu_check.py 的 KEEP。

## 14 同一个词根的几种写法（2026-11 同一个词根轮，project_rules.md 第 61、62 条）

学生看到 produce = pro + duce、product = pro + duct、educate = e + duc + ate，要让他知道这是**一个词根 duc**，不是三个。

```
拆分：pro + duct(=duc)
词根：-duct：词根 duc 的另一种写法（同一个词根）。字母变化：duc → duct，ducere 的“被领出来的”形式是 ductus：duc 后面加 t。意思：duc“领着走”（拉丁语 ducere）→ pro“向前”领 → 被引出来的东西 → 产出的东西 → 产品；（数学）乘积；记：duc ∽ duck（鸭子）：…
```

- 开头固定写 `词根 X 的另一种写法（同一个词根）`（视频、脚本照这句认）；要补一句说明的写进括号：`（同一个词根；准确说是 magn 去掉 n 的 mag“大”）`。
- `字母变化：` 后面先写一条从词根写起的链（`duc → duct`、`cap → cip → ceive`、`fac → fact → fect`），逗号或冒号后面讲**哪个字母怎么了、为什么**：
  加了什么（duc 后面加 t）、变了什么（d 变成了 s）、掉了什么（v 在 t 前掉了）、哪种语言里变的（经古法语磨掉了 c）。最后半句最好是一句学生听得懂的话——视频配音念的就是它
  （先找直接说词根字母的“dic 后面加 t”，其次是最后一句讲“加、变、掉、写成”的）。
- 本行讲清，不写“见 别的词”。同组别的词讲过也要再写一遍；照样板词的说明写时，把只属于样板词的话去掉（“同 prevent”“见音变栏”）；这个词变法不一样的单独写。
- `意思：` 照旧：先词根的意思（引号里，视频卡片上写它）和来源，再接这个词里怎么用。只有本词特别意思的写 `意思是“看过了、看得到的”`。
- 没变的那个写法（educate 的 duc）照旧写 `-duc-：本组词根“领着走”（拉丁语 ducere）→ …`，来源直接写，不写“见 reduce”。
- 过去分词词干也是词根的写法之一：`durat-：词根 dur 的另一种写法（同一个词根）。字母变化：dur → durat，拉丁语 durare“持续”→ 过去分词 duratus → 词干 durat-；…`。
- 记法写词根本身（duc ∽ duck），不写这个变体。

## 15 记法里的“音变”（2026-11，project_rules.md 第 63 条）

≈ 是说“本是一家”。两边写法差得多（fac ≈ do、dic ≈ teach、ped ≈ foot、cord ≈ heart），学生会觉得没有关联，所以要讲清**哪个音、哪个字母对哪个，为什么不一样**：

```
记：fac ≈ do（做）：do 是做，fac 也是做；词典说它们出自同一个印欧语词根。音变：f 对 d：印欧语的 dh，拉丁语在词头念成 f，英语念成 d（印欧语词根 *dhe-“放、做”，fac 后面的 c 是拉丁语加上去的；同 foreign 的 for- 和 door）
记：regul ≈ rule（规则）：rule 是规则，regul 也是规矩；rule 就是从它变来的。音变：regula（拉丁语）→ reule（古法语）→ rule（英语）：夹在两个元音中间的 g 越念越轻，脱落了
```

- 两种写法。**谁对谁**（拉丁语 / 希腊语一支和英语一支，辅音有规律地对应）：`音变：f 对 d：一句话（印欧语词根 *…；同 … 和 …）`，几对用顿号隔开（`p 对 f、d 对 t`）。
  **一条链**（关联词是从这个词根经法语等变来的）：`音变：链：一句话`，链照关联词自己那一行的【字母变化】，可以省掉中间一两步；那一句话只讲最要紧的一处。
- 那一句话不带括号、不带 * 开头的形式（视频配音照念）；印欧语词根（*…）、别的例子放进后面的括号（配音不念，卡片上也不显示）。
- 括号里的“同 … 和 …”尽量用表里的词根和学生认识的词，并且互相引用：p 对 f（ped / foot、patr / father）、d 对 t（du / two、dec / ten、dent / tooth）、t 对 th（tri / three）、
  c 对 h（cord / heart、cent / hundred）、g 对 k（gno / know、erg / work）、f 对 b（fer / bear、frag / break）、v 对 w（vi / way、vin / wine、volunt / will、nov / new）、
  c 对 gh（oct / eight、luc / light、rect / right）。学生看多了，自己就能认出这几条对应。
- 写法相近的不加（vid ≈ video、sta ≈ stand）；∽ 只是长得像、不同源，没有音变可讲。
- 同源关系先查 etymonline（两个词是不是同一个 PIE 词根）；词典说不确定的照写“一说”（thermo ≈ warm）。内容统一放在 `scripts/part_memo_data.py` 的 SHIFT，`part_memo.py` 写记法时自动接上。

## 17 身份和分工怎么写（2026-11 身份分工轮，project_rules.md 第 67 条）

要回答学生的两个问题：**这个写法（这个词缀）是什么来头？为什么这个词用它、那个词用另一个？**

词根族（写进 `shenfen_data.py` 的 FAM）：
1. 先把这一族在表里的写法列全（`python3 scripts/shenfen.py <表>` 会提示没找到身份的写法），每个写法定身份。判断的依据就是那一行“字母变化”里已经写的话：
   “去掉动词词尾 -ere，英语加不发音的 e” → 动词原形（V）；“…的“被…了的”形式是 …us：后面加 t / d 碰上 t 变成 s” → 过去分词（P）；“放进复合词，元音 a 弱化成 i” → 接在前缀后面（W；过去分词又弱化的 PW：fect、cept）；
   “到古法语成了…” → 经法语（F；过去分词经法语 PF：feat、prise）；“i 是连接元音” → 带连接元音（L）；“名词 genus 的词干”“形容词 plenus” → 名词 / 形容词的词干（N / A）；“由它造出动词 …are” → 另一个动词（D）；“过去分词 …atus → 词干 …at-” → -at- 过去分词词干（T）。
2. 分工那句话：一个（一类）写法一条，“；”隔开。每条先说身份，再说**用在哪儿**（当动词 / 当名词、形容词 / 后面接 -ion、-ive、-or / 前面有前缀时 / 经法语来的词里），括号里放两三个总表里的例词。
   先写最要紧的对比（动词原形 ↔ 过去分词），生僻的写法放最后、一句带过（“dit 只在 condition 里，是晚期拉丁语的误写”）。
   英语把过去分词直接当动词用的（conduct、insert、predict）要点明，不然学生会问“duct 不是当名词吗”。
3. 不写句号；不写“意思是“…””“意思：”；条首用写法本身开头（`duce 是…`、`-ful…是…`），视频靠它认这一条讲的是谁。

词缀（写进 `cizhui_catalog.py`）：
- 身份一句：从哪种语言来（英语本族 / 拉丁语 / 希腊语 / 法语，括号里写原来的样子 -osus）、接在什么词后面、强调什么。同一个写法两种用法各写各的（-al 形容词 / 名词；-ly 副词 / 形容词；-er 人 / 比较级；in- 不 / 向里）。
- 分工组一句：开头“同样是把名词变成形容词：”当总说；然后本族的一类、外来的一类，或者一个词缀一条；讲**差别**（本族的接日常的词、英语自己造词用它；拉丁语来的多半跟着整个词借进来、书面一些；-al、-ic 只说“和…有关”；-ive 接动词、主动；-able 接动词、被动……）。
- 这些都是“多半、一般”的趋势，不是铁律：分工里用“多”“一般”，具体到某个词为什么用它，查了词典再写“为什么用…”那一行。

## 18 辨析列怎么写（2026-11 辨析列轮，project_rules.md 第 68 条）

- 【同义词】行不手写，用 `bianxi.syn_lines` 算（含义改了要重算）。只有程序对不上的（中文说法不一样、其实是一回事）才手加，格式 `【同义词】中文意思：本词、词2（它的说法）、词3`。

## 19 拉丁语动词的三个样子（2026-11 拉丁语动词变化轮，project_rules.md 第 71 条）

要回答学生的问题：**“动词原形”“过去分词”到底长什么样？duct 的 t、vis 的 s 是怎么变出来的？** 写在词根那一行“身份：”的前面，整族同一句：

```
-duct：词根 duc 的另一种写法（同一个词根）。字母变化：duc → duct，ducere 的“被领出来的”形式是 ductus：duc 后面加 t。动词变化：原形 ducere“领”→ 过去式 duxi“领了”→ 过去分词 ductus“被领的”；规律：过去式是 duc 加 s，c 和 s 合写成 x；过去分词是 duc 加 t。身份：过去分词的样子（…）。分工：…。意思：duc“领着走”（拉丁语 ducere）；记：…
-gress：…。动词变化：原形 gradi“迈步走”→ 过去分词 gressus“走过了的”；规律：这个动词只有被动的样子，没有单独的过去式；过去分词是 grad 加 t，d 碰上 t 变成 ss，a 也变成了 e（写成 gress）。身份：…
```

不手写进表：改 `scripts/dongbian_data.py` 的 VERB，用 `dongbian.py --write` 写回。一条数据：

```python
(306, 'duc'): dict(inf=('ducere', '领'), perf=('duxi', '领了'), pp=('ductus', '被领的'),
   rule='过去式是 duc 加 s，c 和 s 合写成 x；过去分词是 duc 加 t'),
```

1. **三个样子**查词典的主要形式（Lewis & Short、Wiktionary 的 Latin 条目写作 dūcō, dūcere, dūxī, ductum）：原形取第二个（不定式），过去式取第三个（第一人称单数完成时），过去分词取第四个、写成 -us。不写长音符号。
   没有第三个形式的异相动词（词典写 gradior, gradī, gressus sum）`perf=None`。查不准、古典拉丁语里见不到的形式不写（ovare 的 ovavi），这一族宁可不收，记进 SKIP。
2. **中文**要短（画面上写在框的左下角）：原形两三个字（领、看、拿、抓），过去式加“了”，过去分词“被…的 / …了的”，照这一族“分工”里对过去分词的说法（站定了的、看过了的、被推动了的）。
3. **规律**先过去式、后过去分词，“；”隔开（视频按“；”一句一行，最多三行；四句以上会连着排）。每一句回答“在词根上动了什么”：
   - 加了哪个字母、和谁合写：`duc 加 s，c 和 s 合写成 x`、`aug 加 t，g 在 t 前面写成 c（写成 auct）`、`vid 加 t，d 碰上 t 变成 s（写成 vis）`、`mov 加 t，v 在 t 前面掉了（写成 mot）`；
   - 没加字母的说清变了什么：`只换元音，a 换成 e`、`只把元音 i 念长，写法不变`、`把开头的音重复一遍（ce-cid-i）`、`不变样，词根直接加词尾`；
   - 原形里才有的东西点出来：`原形中间多出一个 n，只在原形里有`（frangere）、`原形里的 sc 是“渐渐”，只在原形里有`（crescere）、`原形里的 r 本来是 s`（quaerere、gerere）；
   - -are 这一类用现成的那半句（ARE），括号里点一个表里的词：`（vocation 的 at 就是它）`。
4. **念出来的部分只用词根、单个字母和中文**；拉丁语的整词（plicitus、creatus）、英语的例词放进括号——括号里的字视频画面上有、配音不念。词根三个字母以内的配音会一个字母一个字母念（d u c）。
   不成词的字母串（cre、ges、sting、fluc）尽量少用：能说“它”就说“它”（“词根原来带一个 g 的音（strug）；过去式是它加 s”）。
5. 不写句号，不写“意思是“…””“意思：”，不写“身份：”“分工：”“；记：”这些别的段的标记。和这一族各行“字母变化”一段说的是同一回事，说法别打架（那一段说“v 在 t 前掉了”，这里就不要说“v 变成了 u”）。

## 20. 词缀的来历和记法（2026-11 词缀来历、记法轮，project_rules.md 第 73–77 条）

**来历**写在前缀、后缀那一行的来源括号里，一个词缀（一种用法）全表同一句，目录在 scripts/laili_data.py：

| 词缀 | 来历 |
|---|---|
| pro- | 来自拉丁语介词 pro“在前面、向前”，本来是单独的一个词 |
| re- | 来自拉丁语前缀 re-，本义“往回”，往回再来一次就是“再”（后面照旧接“；只用在词前，不单独成词”） |
| un-（不） | 英语本来就有，古英语 un- |
| en- / em- | 来自法语 en-，往上是拉丁语介词 in“在…里、进入” |
| -ly（副词） | 来自古英语 lic“身体、样子”，本来是一个单独的词：带着…的样子 → 以…的方式 |
| -ion | 来自拉丁语名词词尾 -io，变格时写作 -ionem，经法语磨成 -ion 进入英语 |
| -less | 来自古英语 leas“没有的、丢了的”，本来是一个单独的词 |

- 讲清四样：哪种语言、原来是什么（单独的词 / 词尾）、什么意思、怎么进入英语。学生最该知道的是“它本来是一个词”（pro、ad、sub 是拉丁语的介词，-ful、-less、-ly 是古英语的词）。
- 不写：同源的英语简单词（写在记法里）、例词（“同 例词”照旧跟在后面）、括号套括号。“经…”前面只写来源语言（视频认来源靠它）。

**记法**写在那一行最后，和词根的记法一样：`；记：X ≈ Y（中文）：道理。音变：谁对谁：一句话（印欧语词根 *…；同 …）`。
- X 写词缀本身，不带连字符（ly、ful、sub）；同一个词缀的别的写法也写它本身（sup- 写 sub，im- 写 in，em- 写 en，ac- 写 ad）。
- 道理的第一句要能单独看懂（卡片“记”框只显示两行），先讲最关键的那层关系。例：
  - `sub ≈ up（向上）：同一个印欧语词根既是“在下面”，又是“从下面往上”：拉丁语留下了“下”，就是 sub；英语留下了“上”，就是 up。所以 sub 有时也是“从下面往上”：support 就是从下面往上托住，sup 就是 sub`

  - `ful ← full（满的）：-ful 就是 full 变来的：装满了…，就是“充满…的”；当后缀只写一个 l`
- 词典只说“也许”的写进道理（trans ≈ through）；两个都说得通的都写（bio：zoo、quick）。

## 音变的原因（2026-11 音变原因轮，project_rules.md 第 99–101 条）

记法后面的音变是格林定律管的（p、t、k → f、th、h；b、d、g → p、t、k；bh、dh、gh → b、d、g），末尾接四块原因，一律用 `yuanyin.add(句子, 记法的关联词)` 生成，不手写：

`；原因：〈总说〉；发音：念 p，〈怎么念〉，念 f，〈怎么念〉，两个音〈像在哪儿、差在哪儿〉，所以 p 容易念成 f；起因：没有定论，一种说法是〈……〉；例子：拉丁语 piscis 和 fish、plenus 和 full、paucus 和 few`

- 发音讲“为什么能变”：两个音发音部位一样，只差一点（闭不闭紧、顶不顶住、声带振不振、带不带一股气）。说法要学生照着嘴型能做出来。
- 起因讲“为什么这样变”：学界没有定论，只写“一种说法是……”，不写成定论。
- 例子是逐个对过 etymonline 的标准同源词，不和这一句、记法里已经出现的词重复。
- 原因里不能有句号，“发音”这一块里只用逗号（视频按记号和“两个音”切）。
