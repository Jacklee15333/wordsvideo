# 含义词性分行轮（2026-11）的一次性脚本，只作记录

做法：原表含义列（一行，“；”隔开，词性只在换词性处用括号标）→ 每个意思一行、行首写词性。

| 文件 | 做什么 |
|---|---|
| seg.py | 切开含义：括号、引号外的“；”，括号外的 ②③（同形词） |
| ecd.py | 读 ECDICT（https://github.com/skywind3000/ECDICT 的 ecdict.csv，按表里的词抽成 pkl）：每个词各词性的中文释义 |
| posify.py | 自动定词性：括号标签 → 中文写法（…的 / …地 / 使…）→ 第一个标签前面那一段的默认词性（ECDICT 比对、例句、组合列词性变化投票，打平时用 WordNet 频率）→ 标签后面的接着用标签的词性；给拿不准的打标记 |
| overrides.py | 人工核对的结果：POS（改词性）、LINE（整行重写，可拆成几行）、TXT（改正文）、MERGE（说明并进上一行括号）、MOVE（挪到 L 列）、DROP、FIX（内容改错，写进 Q 列） |
| render.py / assemble.py | 拼成新的含义列，检查每行都有词性、一行一个意思 |
| write_book.py | 写回总表：F 列、L 列【派生】【合成】【联想】、J 列“见含义列”、Q 列“含义词性：…”、「整表核对记录」、「说明」、行高 |

路径写死在 /home/claude/ 下，要重跑得先改路径、重新下载 ECDICT、pip 装 nltk 和 wordnet。以后补新词不用这些：照 references/writing_guide.md 第 7 节手写，跑 `python3 scripts/meaning.py <xlsx>` 体检。

## round2/：例句分列轮（同月）

| 文件 | 做什么 |
|---|---|
| ex_split.py | 一个意思拆成“干净的意思 + 例子”：括号里英文开头的算例子；年代、“X 的复数”、“也叫…”、“= X”、中文是说明；“说明：例子”拆开 |
| build2.py | 把上一版（一个意思一行）每行拆好，存 senses0.pkl |
| overrides2.py | 人工改：意思写成例句的改成中文意思、例子夹在中间的、拆行后没跟上的词性 |
| build3.py | 同词性并成一行，生成例句列（“意思：例子”，重了的带标签、再加词性） |
| write_book2.py | 在 F 后面插 G「例句」，后面的列往右挪；R 列记录、「说明」「整表核对记录」改列字母和公式 |
