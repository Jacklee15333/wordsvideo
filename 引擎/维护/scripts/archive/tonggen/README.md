# 用词规律轮 + 同一个词根轮（2026-11）用过的脚本，只作记录

顺序：先把总表读成 table.pkl（表头 + 每行 16 格），再跑：

1. `lst.py` / `lst2.py`：把某一条规律下的所有行按“本词 A → B｜这一步的说明”列出来，人工逐条判断。
2. `codes_all.py`：“用进某一行”571 行、“英美不一样”290 行的判断结果（每行 10 条；c 核心不变、f 作用像、s 样子像、n 专指、x 不标……）。
   `codes_rev2.py`：其余规律的复核（“动作 → 用的东西”“动作 → 做出来的东西”全看；别的按词性对不上的看）。
3. `ws1.py`：按上面的判断改组合列的规律行（同一步不写两遍、同一条规律第二次出现只留熟悉的例子），camera / produce / product 手写。
4. `ws23.py`：词根列——“由词根 X 变来”改写成“词根 X 的另一种写法…字母变化…”，去掉“见 同组的派生词”，记法换词 / 待补 / 写词根本身 / 补音变；拆分加 (=X)。
   `shift_notes.py` 是音变的内容（已并进 scripts/part_memo_data.py 的 SHIFT）。
5. `build_out.py`：把两份改动合起来，用 scripts/xlsx_write.py 写回 xlsx。

这些脚本里的路径是当时沙盒里的（table.pkl、sk_table/…），再用要先改路径。
