# 分三列轮（2026-11）的一次性脚本，只作记录

| 文件 | 做什么 |
|---|---|
| split3.py | 试分：各部分解释每一行按标签分到前缀、词根、后缀三列，查有没有丢行、合起来先后变了多少 |
| write_book3.py | 写回总表：J 各部分解释换成 J 前缀、K 词根、L 后缀，后面的列往右挪两列；T 列记录；「说明」「整表核对记录」改列字母、公式和写法说明 |

分列的规矩写在 scripts/cols.py（split_parts），以后补内容用 cols.set_parts，不用这里的脚本。
