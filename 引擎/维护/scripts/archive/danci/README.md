# 单词列轮（2026-11）的一次性脚本，只作记录

| 文件 | 做什么 |
|---|---|
| decisions.py | 词根列里每一行去哪儿的人工判断：W（其实是英语单词，去掉连字符，进单词部分）37 处、R（其实是外语成分、拉丁词根，留词根列、加连字符）253 处、P（其实是前缀）5 处，外加 9 条说明行 |
| apply.py | 自动规则 + decisions.py：算出新的前缀、词根、单词部分三格和 U 列记录；检查合回一格的内容和原来一样 |
| write_book.py | 写回总表：K 后面插 L「单词部分」，后面的列往右挪一列；「说明」「整表核对记录」改列字母、公式、写法说明，补第 104–106 条 |
| idem_test.py | 回归测试：每行四格合回一格再用 cols.cells 分回四列，必须一模一样 |

以后补内容用 scripts/cols.py 的 set_parts（原来的行照原来的列放，新行用 is_word_part 判断），不用这里的脚本。
