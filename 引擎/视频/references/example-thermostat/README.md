# thermostat：5.1 的样例（记法 + 按句出的示意图）

- 总表（部分记忆版）thermo、stat 两行末尾写了“；记：thermo ≈ warm（暖和的）：…”“；记：stat ≈ stand（站）：…”：两张卡片都有黄色“记”框，配音念“记法：stat，约等于 stand，站。……”，小黑板多一行“记”。
- `prefs.json`：
  - `icons`：`"p1": "🧍"`——stat 的卡片配音讲 stand（站），图就画站着的人，不用自动配的“名词”牌子；`role`：`"p1"` 把“让…站住不动”写成完整的一句。
  - `pics`：恒温器特写（`room` 背景），屏幕上的数字 19° → 22° 一个个换，暖气上方的热气到 22° 时停掉；例句动画：手指按一下，数字从 18° 调到 22°，暖气开始冒热气。
  - `flow`：演变那一步配音拆成三句，示意图（温度计 + 暖气 + 恒温器）按句出东西：太冷 → 暖气冒热气、红柱往上长（`reveal: up`）；太热 → 热气停、红柱降到 22° 那条线（`col-high` 消失、`col-mid` 淡入）；停在 22° → “站住不动”。
  - `lexicon`：thermo 的读音。
- `art/`：恒温器、暖气片、温度计（玻璃管 + 三种高度的红柱，viewBox 一样，叠在一起正好对齐）。
