# 用户的两张表

## 词源总表（必需）

比如“词源拆分总表_单词列版.xlsx”：4 个工作表，只读“拆分结果”（九千多个单词）；“用词规律一览”“整表核对记录”“说明”不读。列名在第一行：

| 列 | 用来做什么 |
|---|---|
| 单词 | 认词（大小写、结尾的点不算区别：Wed. 和 wed 都能找到，各是各的） |
| 组号 | 同一组号的词是一个词族（“同一词族”那一幕；“背景”借用） |
| 含义 | 现在的意思（2026-11 起单独一列，原来是组合列最后的【今义】）：同一词性的意思写一行，行首写词性，意思之间用“；”（adj. 受欢迎的；流行的、大众的 / n. 比赛；对手 / phr. carry out 执行），（英）（口）这类标签写在意思前面，同形词的 ①② 写在词性后面，不带例子。开头那句（第一行的第一个意思）、“现在的意思”那一幕（每个意思和它的词性牌）、小黑板都用它。老表（一个意思一行、例子在括号里，或“；”隔开、括号里写词性）照样认 |
| 例句 | 例句、例词（2026-11 起单独一列）：每个有例子的意思一行“意思：例子；例子”（受欢迎的：a popular teacher）；“意思”和含义里那个意思（去掉括号）对得上，重了的带标签或前面加词性。每个意思配的例句、“现在的意思”那一幕念的例子从这里来 |
| 类型 | ① 词根词缀 / ② 变体关联 / ③ 合成词 / ④ 不好拆分 / ⑤ 基础词，标在单词上方 |
| 拆分 | `trans + port`（拆开讲）、`made ← maked`（变体）、`set ≈ sit`（同源）、`—`（基础词）、`competit(=compete) + ion`（名词、形容词接在拉丁语过去分词词干上：前面是词干，括号里是母词；4.0 起）、`pro + duct(=duc)`（这一部分是词根 duc 的另一种写法；5.11 起） |
| 前缀、词根、单词部分、后缀 | 2026-11 起“各部分解释”拆成这几列：前缀列每个前缀一行“re-：…”；词根列是不能单独用的词根（带连字符“-ped-：…”“bio-：…”，读的时候去掉）和连接成分，写在词根列的部分一律画成词根卡片；单词部分（单词列轮起）是能单独用的英语单词——基础词本身、母词、合成词的各个词（“make：做（见 make）”“up：…”），画成单词卡片、配音“单词是 make”；后缀列每个后缀一行“-ion：作用（来源；同 例词）”；“为什么用 -er 不用 -or”跟着它讲的那个词缀；没有的写“-”。ety_table.py 读表时把几列合回一格“各部分解释”（词根和单词部分的行按拆分里的先后穿插），卡片上的小字和图从这里来 |
| 各部分解释（老表） | 每行“部分：意思”，卡片上的小字和图从这里来。后缀行的格式是“-ion：作用（来源；同 例词）；在这里：动词 → 名词。……”，来源、词性变化、“在这里”自动用上；（“同 例词”2026-11 例词清理轮起只留“单词 + 这个词缀”的简单例词，不少行已经没有例词；详细版的“比如 X”有才念）另有“意思怎么变：……〔用词规律①〕”“用词规律：① ……（例子）”两行，用在演变链和小黑板，不算部分 |
| 组合 → 现在的含义 | 【构词逻辑】第一行是等式“trans（到另一边）+ port（搬运）=“搬到另一边””，下面 → 开头的几行是意思的变化；现在的意思在「含义」列（老表写在这里的【今义】也认）。合成词、带连字符的词第一行下面还有“　合成规律：”“　写法：”两种行（3.7 起读进“合成规律”那一幕和小黑板）；接在拉丁语过去分词词干上的词，第一行下面还有一行“　构词：…”（4.0 起读进“构词”那张卡和小黑板） |
| 辨析（6.0 起，总表“辨析列”轮） | 第三部分“同义词辨析”的材料：`【同义词】产品：product、produce（农产品）` 几行（中文意思一样的几个词，都在总表里）+ 辨析的话（原来写在组合列的【辨析】段）+ 可以有一行“逻辑不同：…”。读法见下面“辨析列”一条 |
| 考点（6.11 起，总表“考点版”第 18 列） | 视频“考点”那一部分（总结前面）：一行一个【变形】【词性转换】【短语】【用法】【易混】，维护技能 kaodian.py 写；视频 `kaodianOf` 读，变形按“ / ”分词性、别的按“；”分条；6.31 起（第七十五版，第 126 条）每个词都写详细，一页放不下分两页 |
| 题目1–题目7、答案（6.14 / 6.15 起；6.31 起 7 道，题目6、题目7 是第 24、25 列，答案第 26 列） | 视频“练习”“答案”两部分：一格一道题（【题型】要求 / 听： / 中文： / 题干： / A–D / 考点：），答案一格七道（【1】D（…） / 讲解：…）；维护技能 lianxi.py 写，视频 `lianxiOf` 照读 |
| 新·背景（只写在词族第一个词上） | 词族的来历故事；族里其他词借用第一个词的 |
| 音变 / 字母变化、原表备注 | 写来历、讲同源时参考。第一行是【字母变化】链的：变体（people ← popul）、≈ 的词“怎么变来的”那一幕照链一步步变字母（3.5、3.6）；写成过去分词词干的词（describere（拉丁语）→ descriptus（拉丁语）→ descriptio（拉丁语）→ description（英语），总表“过去分词音变”轮起）视频暂不读，它们的链在组合列“构词”那一行，做成“构词”卡 |
| 核对结果、核对依据、来源链接 | 视频里不用 |
| 本次调整、词根变体处理 | 维护记录，不读 |
| 批次、序号、小类号 | 不用 |

读表的规矩（总表由维护技能 etymology-table 按这些写、用它的 `video_check.py` 体检）：
- 含义、例句（2026-11 起）：含义同词性一行、行首写词性；例句每行“意思：例子”。wordfilm.js 的 `fromPosLines(含义, 例句)` 先合起来还原成“（n.）比赛（a football match）；（v.）相配”再读，`ety_table.py` 的 `meaning` 取含义第一行的第一个意思。维护技能的 `meaning.py` 是同一套写法（读、还原、体检）。
- 组合公式（2026-11 起）：第一行都是“母词（意思）+ 后缀（后缀的意思）=“字面意思””，不再写派生路线，只有截短、缩写、变体这类写不出组合公式的还写“派生路线：…”。
- 清爽格式（2026-11 起，现在的总表）：【构词逻辑】第一行末尾是“；词性变化（-or）：动词 → 名词”（几个后缀接成一条“（-less、-ly）：名词 → 形容词 → 副词”）；下一行可能有后缀等式“X“…”+ -or（…）=“…””；用词规律不编号，写在用到它的那一步下面一行“　用词规律：……”。wordfilm.js 读之前先还原成下面的融合格式。几个后缀的英语派生词，拆分用直接母词（thoughtless + ly）。
- 三列分工、组合列融合：各部分解释只讲各部分；组合列【构词逻辑】等式下面一行“词性变化（-er）：动词 → 名词。make“做”加上 -er（…的人），就成了“做东西的人””（就是后缀卡片的“在这里”：配音念“加上 -er”后面那句，括号不念），用到用词规律的步骤末尾标〔用词规律①〕，下一行“　用词规律①：规律（例子）”。上一版写成【词性变化】【用词规律】两段，老表把它们写在各部分解释里（“在这里”跟在后缀行里，另有“意思怎么变”“用词规律”两行），也认。
- 拆分按括号外的“ + ”切；X(=Y)、X(Y) 括号里是注释或省掉的字母；两种拆法用“；”隔开，只读第一种。
- 各部分解释每行“标签：解释”，标签可以带括号、可以一行写两个；“意思怎么变”“用词规律”两行不算部分。
- 【构词逻辑】第一行要有等式 `A（…）+ B（…）=“字面意思”`（几条路用“ / ”隔开），或“派生路线：X（…）→ Y（…）”最后一步带意思；→ 和 ①② 开头的行是意思的变化；每个词有【今义】。
- 拆分里 e 结尾的词加后缀写全（make + er、use + ed、time + ing），拼起来比单词多一个 e；视频对字母时会把前一部分末尾的 e 去掉（3.8 起）。
- 合成规律、写法（2026-11 合成规律轮起）：“　合成规律：规律那句话（本词：短语 → 本词；同 例词）”“　写法：规律那句话（例子）”，紧跟在第一行（和后缀等式）下面；规律那句话没有括号，第一个“（”前面就是。规律那句话照维护技能「合成规律一览」，视频照念；维护技能用 hecheng_check.py 体检。
- 记法（5.1 起，总表“部分记忆”轮）：前缀、词根、后缀那一行末尾“；记：stat ≈ stand（站）：道理”（≈ 同源、∽ 只是长得像、← 从它变来），读成卡片的“记”框、配音“记法：…”、小黑板“记”一行；“可以这样记：toddle / totter…”这类后面不是“X ≈ Y”的老说明不当记法。
- 同一个词根的几种写法（5.11 起，总表“同一个词根”轮）：拆分写 `pro + duct(=duc)`；词根列那一行写“-duct：词根 duc 的另一种写法（同一个词根）。字母变化：duc → duct，ducere 的“被领出来的”形式是 ductus：duc 后面加 t。意思：duc“领着走”（拉丁语 ducere）→ …”。
  `variantOf` 读出：词根（开头那句）、字母变化的链（“字母变化：”后面到第一个逗号 / 冒号）、怎么变的（后面那段；配音念的半句先找直接说词根字母的“dic 后面加 t”，其次是最后一句讲“加、变、掉、写成”的）、词根的意思（“意思：X“…””或“意思是“…””引号里的）。
  老表的“由词根 duc 变来。词形：…”“由词根 duc 变来（duc → duce，见 reduce）”照样认。词根行里不再有“见 同组别的词”。
- 记法里的音变（5.11 起）：≈ 两边写法差得多的，记法后面接“。音变：f 对 d：印欧语的 dh，拉丁语在词头念成 f，英语念成 d（印欧语词根 *…；同 … 和 …）”（“谁对谁”几对用顿号隔开），
  或一条链“。音变：regula（拉丁语）→ reule（古法语）→ rule（英语）：夹在两个元音中间的 g 越念越轻，脱落了”。`shiftOf` 读成 pairs / chain + 一句话；配音念那一句话（括号里的不念）。
  词根和单独的词写法一样的记法（port ≈ port（港口））配音念“port 单独用也是一个词，意思是港口”。找不到简单关联词的行没有记法（总表「词根变体处理」列标“记法待补”，视频不读这一列）。
- 用词规律（总表“用词规律”轮起）：“一个词用进某一行…”“同一个词，英国、美国…”两条取消了，换成“词的核心意思不变，换了对象、场合，中文要换个说法，英语还是这个词”“作用、做法像什么，就借它的名字来叫”“东西换了代，干的还是那件事，旧名字就接着用”等；读法没变（规律那句话、本词的例子、熟悉的例子）。手写 flow 的 rule / ruleEx 时照新说法写，熟悉的例子要画出来（phone 电话 → 手机）。
- 后缀行：来源写在括号里（正文里写的也认），“在这里：A → B。……加上 -xx，……所以 ……”，这一段里不用“；”。
- 词缀的关系（6.3 起，总表“词缀关系版”）：辨析的最后可以接一段 `；关系：一条；一条`（同一种语言来的几个词缀彼此是什么关系：`-ant、-ent 是同一个拉丁语现在分词词尾的两种写法，…（important、different、assistant）`）。
  `fengongRows` 先把它切出来（`rows.rel`），`relRows` 认每条开头连着的词缀；讲本词缀的一两条画在“关系”框里、念第一条。写法：“；关系：”只出现一次、在辨析最后；每条开头写词缀；没有句号；括号里是不用念的补充。
- 词缀的身份、记、辨析（6.2 起，总表“词缀身份辨析版”）：前缀列、后缀列讲词缀的那一行写成
  `pro-：身份：“向前”（来自拉丁语介词 pro“在前面、向前”，本来是单独的一个词）；也表示“预先”；这里是“向前、到前面来”；记：pro ≈ for（为了）：…。辨析：同样和“前面”有关：pre- 是拉丁语来的，…（preschool、prehistoric）；pro- 也是拉丁语来的，…（progress、produce）；fore- 是英语自己的，…（forehead、foreground）`。
  “身份：”紧跟在“标签：”后面（开头的介绍就是身份）；“；记：…”在中间；“。辨析：…”是这一行最后一段，前面是句号，里面没有句号，到行末为止。没有记法、没有辨析的行就只有“标签：身份：…”。
  `bianxiOf` 在 `partLines` 里先把记号和辨析拿掉（`idNew`、`bx`），剩下的照老办法读；辨析按“；”切成条（`fengongRows` 的 bx 模式）：开头“同样…：”“这几个…：”是总说，每条开头连着的词缀（用“、”隔开）是写法，括号里全是英文的是例词。
  词缀行下面单独一行“为什么用 -ous 不用 -y / -ful：…”照旧读成 `why`。上一版的写法（下一条）照样认。
- 身份和分工（6.0 起，总表“身份分工”轮；6.2 起只有词根行、和上一版总表的词缀行是这个写法）：词根、前缀、后缀那一行里有一段“身份：…。分工：…”——
  词根行写在“字母变化：…。”后面、“意思：…”前面（`…duc 后面加 t。身份：过去分词的样子（…）。分工：duce 是动词原形的样子，当动词（produce、reduce、introduce）；duct 是过去分词“被领出来的”，当名词（product）…。意思：duc“领着走”（拉丁语 ducere）；记：…`）；
  用原形的词根行、前缀行、后缀行写在行末（“；记：”前面）：`…（同 famous 著名的）；身份：拉丁语来的形容词后缀（-osus）…。分工：同样是把名词变成形容词：-ful（充满）、-y…是英语自己的…（careful、rainy…）；-ous（充满）、-al 和 -ic…是跟着拉丁语、法语、希腊语的词进来的…（dangerous、national、basic）`。
  `shenfenOf` 把这一段从正文里取出来（卡片上的小字、“字母变化”“意思”照旧读）；`fengongRows` 把分工按“；”切成条：开头“同样是…：”“这几个…：”是总说，每条括号里全是英文的是例词，条首的英文是写法。
  词缀行下面单独一行“为什么用 -ous 不用 -y / -ful：…”读成 `why`（“身份和分工”那一幕最下面的黄框）。
  词根列从这一轮起只讲词根本身：“词根的意思 → 前缀“…”… → 今天的意思”那条链不在词根行里了（在组合列）；组合列第一行下面多了一种行“　合起来：拉丁语 efficere“做出来、做成”→ …”，视频暂不读。
- 动词变化（6.1 起，总表“动词变化版”）：词根是拉丁语动词的（57 个词根族、318 行），词根那一行“身份：”的前面多一段
  `动词变化：原形 ducere“领”→ 过去式 duxi“领了”→ 过去分词 ductus“被领的”；规律：过去式是 duc 加 s，c 和 s 合写成 x；过去分词是 duc 加 t。`
  （没有单独过去式的动词只有两个：`原形 gradi“迈步走”→ 过去分词 gressus“走过了的”；规律：这个动词只有被动的样子，没有单独的过去式；过去分词是…`）。
  `verbOf` 把这一段从正文里取出来（先于 `shenfenOf`）：`forms`（k 原形 / 过去式 / 过去分词、la 拉丁语、zh 中文）、`rule`（规律那句话）、`rules`（按“；”切开的几句）。只有这一行也写了“分工”才上画面。

  这一段是整个词根族共用的（同族每一行同一句）；这一行用的是哪个样子不写在这一段里，由身份定（`verbSlot`：身份里有“过去分词”→ 过去分词那个框，“动词原形 / 词根本来的样子 / 接在前缀后面的样子”→ 原形那个框，别的不描边）。
  规律里括号里的字画面上有、配音不念，所以拉丁语、英语的整词都写在括号里。上一版总表没有这一段，视频照 6.0 的样子做。
- 辨析列（6.0 起）：`【同义词】中文意思：本词、别的词（它的说法）、…` 最多 3 行、每行最多 6 个词；下面是辨析的话，一句讲一个词的写成“product 是可数的“产品”：…（a new product 一件新产品）；produce 是…”（句首是英语词）；“逻辑不同：…”单独一行。
  `distOf` 挑一组做第三部分：按【同义词】行的先后，哪一组里别的词在辨析的话里有讲它的那一句（或者它自己那一行的辨析也在比本词）就用哪一组，本词 + 最多两个别的词；
  没有【同义词】行的，用每个分句开头拿来比的、总表里有的词（historic / historical）。每个词：`gloss` 中文意思（【同义词】行括号里的说法，或那一句开头引号里的）、`note` 区别（那一句去掉开头的词）、`ex` 句末括号里的英文例子、`literal` 字面意思（那个词自己组合列等号后面的）。
  拼不出来（辨析的话没讲这几个词的区别）就没有第三部分，起草时提示。手写见 narration-guide.md 第三节的 `distinguish`。

`ety_table.py build` 把整张表读成 json（约 15 秒），`detail` 取出每个词的详情，格式和用户的“单词对照台”软件一样，另外多两项：`extend`（扩展词候选，见下）、`syn`（6.0 起：辨析列里提到的、总表里有的词，各带它自己那一行的含义 `meaning`、短意思 `m`、拆分 `split`、组合列第一行 `logic1`、辨析 `bianxi`）。
表里没有的词（简单词库里的词，比如 everything、teacher）做不了，告诉用户。
变形词（students、went）找不到时用原形（student、go）的词源，视频讲的是原形。

## 音节划分表（读音拆分，5.0 起）

比如“音节划分_总词库7869词_细分版.xlsx”：读“音节划分”工作表（单词 | 音节划分（细分版）| 关键解释），另外读“待复核”（第三列写的需要确认的地方，起草时打印）、“跳过的条目”（短语、带连字符的词）。

- 第二列是富文本，字的样式就是标注（和表里“说明”一致）：**红色删除线** = 不发音的字母，**蓝色下划线** = 固定组合（两组挨着用单线、双线），**绿色加粗** = 元辅e 里读字母音的元音，**紫色加粗** = 音变、特殊读音；“ + ”分块。视频里的字母照这个样子画。
- 6.3 起：关键解释里冒号前是“u_e、a_e、e_e、y_e…”的（元辅e：`u_e：e 不发音，让 u 读字母音 /juː/`），画面上标题写规则的名字“元辅e结尾（uce）”，配音念“元辅 e 结尾：…”；表不用改（`noteShow`、`note_say`）。
- 第三列“关键解释”每行一条（“du 读 /dʒu/：d 碰上 u 的 /j/ 连成 /dʒ/（像 did you）”）：做成“关键解释”那一幕，一条一张卡；“X 读 /…/”的音照表改（词典是 /djʊ/，表里写 /dʒu/，就念 /dʒu/）。
- 每一块的读音：先用 `--unit-list` 单词表的“音标”列（课本音标），没有就用语音模型自带的英式词典（表里“说明”写着英音为准），按字母一个个对到音上（`scripts/syllables.py`，全表 99.3% 对得齐）；表里划掉的弱读元音，词典里还读的，也去掉（different /ˈdɪfrənt/）。对不齐的词只念整词，起草时打印“对不齐”。
- 带连字符的词（well-known）表里跳过了，用几个词各自的拆法拼起来。表里没有的词：这个视频没有读音拆分那一部分（起草时打印）。
- prefs 里可以改：`"pron": false` 不要读音拆分；`"ipa": "/ˈkæmərə/"` 整词音标；`"sylIpa": ["kæ", "mə", "rə"]` 每一块的音标（手写为准）。
- `python3 syllables.py show <work>/syl.json camera,education` 看每一块对到的音；`check` 全表试一遍。

run.py 不写 `--syl` 时，在总表旁边和 `/mnt/user-data/uploads/` 里找文件名带“音节”的 xlsx；`--no-syl` 不要读音拆分。

## 扩展词（小黑板“扩展”那一行）

用户的要求：扩展词一定要是词源总表里的词，这样学生顺带记住总表里的其他单词。
`ety_table.py` 的 `related` 从总表里找候选：同一组号的词，加上别的组里“拆分”带着同一个词根（在总表里出现不超过 60 次的部分，ly、ion、er 这种常用后缀不算）、而且各部分解释里意思对得上的词（port“搬运”和 passport 的 port“港口”对不上，不算）。
排序：和本词共用一部分的、本词从它变来的（communicate 之于 communication）靠前；本词加个后缀的（transportation）、带连字符的、专有名词靠后；同一个词换词尾的（report / reporter）只留一个。前 4 个 `pick` 是默认写上黑板的，同一个共用部分最多 3 个（transport：三个 port 的词，加一个 trans 的词）。
`python3 ety_table.py related <work/ety.json> 单词` 看全部候选。只要课本单词表里的词：run.py 加 `--pool 6A-9A.xlsx`（扩展词还必须在这张表里）；给了 `--unit-list` 时，课本表里的词自动排前面。

## 音变的原因（6.5 起；6.6 起分四块）

记法后面的“音变：p 对 f：…（…）”，格林定律管的接一段原因（维护技能 yuanyin.py 写，写法两边一起改）：

`；原因：英语属于日耳曼语，日耳曼语两千多年前把 p、t、k 成批地念成了 f、th、h，这叫格林定律，拉丁语没有这样变；发音：念 p，两片嘴唇先闭紧、再一下子放开，念 f，下嘴唇轻贴上牙、不闭紧，气从缝里擦出来，两个音都用嘴唇，只差闭不闭紧，所以 p 容易念成 f；起因：没有定论，一种说法是……；例子：拉丁语 piscis 和 fish、plenus 和 full、paucus 和 few`

- 块和块之间用“；”，“发音：”“起因：”“例子：”是记号（`whyOf`）；没有记号的是上一版的写法，只画在记框的“原因”一行。
- “发音”照“念 p，…，念 f，…，两个音…，所以 p 容易念成 f（，另外 d 和 t …）”切（`yinbianOf`）：前两段是两块剖面图下面的话，“两个音”开头的是黄条结论，“另外”是第二对。
- “例子”一条一条用“、”隔开，“X 和 Y”，语言写在这种语言的第一条前面（拉丁语 / 希腊语）。原因里没有句号。

## 读音现象（6.26 起，总表第 25 列「读音现象」）

一行一个现象：`【类别】字母：现象。为什么：原因。（例词、古英语写法）`，例：`【清辅音浊化】sp：s 后面的 p 不送气，听起来像 /b/。为什么：……`。wordfilm.js `duyinOf` 读成 `{tag, letters, what, why}`，读音拆分后面一个一幕（`duyin0`、`duyin1`…）。prefs：`"duyin": false` 不要，`"duyinMax": 2` 最多几条。


## 6.32（第七十六版）：「初中含义」列（第 28 列）
总表“初中含义版”在最后加了「初中含义」：写法和「含义」一样（一个词性一行，行首写词性，几个意思用“；”，同一个意思的两种说法用“、”），只留初中常用的意思（protect：v. 保护）。
