## 一、用户定的五条原则（每一幅都要做到）

0. **画成现实生活里的样子（6.20，用户：“要接近真实的样子，不要太抽象，不要只画一个人头，一个摆件这样的；要尽量体现出现实生活中的样子”“所有的单词都要是这样的”）**：每一幅画都是学生在生活里见过的一个场面——**在哪儿**（屋里、教室、舞台、车站、街上……铺一张场景背景）、**谁在用它 / 谁在做这件事**（写实插图的人，半身或全身，正在做配音说的事）、**它在做什么**（出声、亮灯、被人拿着用）。不要摄影棚背景前孤零零一样东西，不要只有一个头，不要表情图。详细做法见第十五节。

1. **讲什么就画什么**：配音这一句说到的东西，画面上此刻就要有，而且一眼看得出是它。来历说“拱顶的屋子”，就画一间拱顶的屋子；说“小孔把屋外的景物映在墙上”，就演光线穿过小孔、墙上出现倒立的像。对不上的画宁可不放（来历卡片没写 originPic 就只写字）。
2. **主角特写**：讲的那样东西放在中间，**至少占画高一半**（`s` ≥ 0.45，起草时自动检查）。照相机就是一台大大的照相机，不是草地上一个小黑点。配角、背景只是衬托。
3. **不要表情人头**：👨👩👧🧒🧑🧑‍🏫 这类表情只有一个头（或半身），学生觉得难看，也说明不了什么（起草时自动检查）。要人就用全身的（🚶🧍🏃🧎 等）；多数时候不需要人——把东西本身画好、画大更清楚。
4. **要实际的形象**：用写实的插图（`svg`，自己画：有渐变、高光、阴影，像真东西），或者用户给的照片（`img`）。3D 表情图只有 256 像素，画大了会糊，而且一看就是图标——6.20 起不用。

## 二、画用在哪儿

| 地方 | 写在 prefs 哪里 | 画框大小（宽 × 高） |
|---|---|---|
| 来历卡片（基础词、变体） | `originPic` | 540 × 356 |
| 现在的意思（两幅并排 / 一幅放大） | `pics[i]` | 537 × 356 / 660 × 450 |
| 演变那一幕右边的大画板 | `flow[k].fig`（没写 fig、但这一步是现在的意思 `pic` 时，用那一幅） | 600 × 448 |
| 例句的大动画 | `pics[i].exPic` | 1120 × 432 |
| 拼起来那一格（拆开讲的词） | `comboPic`（默认第一幅） | 约 400 × 214 |
| 每部分卡片左边（5.11） | `partPics`：`{"p1": {…}}`（p0、p1…是第几部分；不写就用自动配的小动画） | 302 × 约 300 |
| 同义词辨析每个词的卡片上面（6.0） | `distinguish.pics`：`{"product": {…}}`（本词的卡不写就用它那个意思的 `pics[i]`）；整段手写时写在 `distinguish.items[i].pic` | 两个词时约 480 × 118（下面有“逻辑不同”框）/ 170（没有）；三个词时宽约 330 |
| 小黑板（缩小贴上去） | 自动用 exPic | 约 330 × 150；6.1 起总结分两页时贴在第二页每一行的左边，约 300～430 × 140～200（几个意思就几行），比一页时大，画里的小字也看得清 |

同一幅画可以用在几个地方（来历和演变第一框都用拱顶屋子）：东西的位置都是相对画框的（0～1），标签、光线用 `on` 跟着插图走（第三节），换个画框大小也对得上。

## 三、格式

```json
"pics": [
  {"text": "照相机", "pos": "名词", "diff": "能拍下照片的机器", "bg": "studio", "tint": "warm", "flash": [1.25],
   "items": [
     {"id": "cam", "svg": "art/camera.svg", "x": 0.43, "y": 0.5, "s": 0.72, "shadow": true, "anim": "click", "at": 1.2},
     {"shape": "circle", "on": "cam", "x": 116, "y": 144, "r": 0.05, "fill": "#FFFFFF", "glow": 3, "delay": 1.15, "hide": 1.5},
     {"svg": "art/photo-tree.svg", "x": 0.82, "y": 0.5, "s": 0.4, "rot": 6, "delay": 1.65, "pop": true, "z": 3}],
   "ex": "I took a photo with my new camera.", "exzh": "我用新相机拍了一张照片。", "exPic": { … }}
]
```

整幅画的键：

| 键 | 意思 |
|---|---|
| `text` / `pos` / `diff` | 画下面的意思、词性、一句话区别（配音“一是……二是……”念 text） |
| `ex` / `exzh` / `exPic` | 例句、中文、例句动画（第九节） |
| `bg` | 背景（第四节） |
| `tint` | `plain`、`studio` 的颜色：warm / blue / green / pink / purple（studio 还有 gray） |
| `img` | 一张图片（svg / png / jpg）铺满整幅画当背景，东西照样画在上面（房子正面、街景） |
| `flash` | `[秒, …]`：整幅画白光一闪（拍照） |
| `not` | true：整幅画上一道红杠 |
| `evo` / `evoSay` | 没写 flow 时自动拼演变链用（老写法） |

每样东西（`items` 里一项）写下面一种：

| 种类 | 写法 | 说明 |
|---|---|---|
| 写实插图 | `"svg": "art/camera.svg"` | **主角首选**。矢量图，放多大都清楚。路径相对 prefs.json（`~/wordfilm-work/<单词>/`），也可以直接写 `<svg …>…</svg>` |
| 照片 | `"img": "art/photo.jpg"` | 用户给的照片；`frame: true` 加白边，`round: 0.08` 圆角 |
| 表情 | `"e": "🐕"` | 小配角（会换成 3D 图）。**不要用人头表情** |
| 光线 / 箭头 | `"ray": [[x, y], …]` | 从第一个点开始，`dur` 秒“画”到最后一个点；`color`、`lw`（线宽，占画高）、`arrow: true` 箭头、`glow: true` 发光、`dash` 虚线 |
| 标签 | `"label": "小孔"` | 白底小牌子；`to: [x, y]` 拉一条指示线指过去；`size`（字高占画高，默认 0.07）、`color`、`bg`、`border` |
| 形状 | `"shape": "circle"` | `circle`（`r`）、`rect`（`w`、`h`、`r` 圆角）、`ellipse`（`w`、`h`）、`poly`（`pts`：相对 (x, y) 的几个点，按画宽、画高算）；`fill`（一个颜色或几个颜色的渐变）、`stroke`、`lw`、`glow` 发光 |

共同的键：

| 键 | 作用 |
|---|---|
| `x`、`y` | 中心位置，0～1（左上角 0, 0） |
| `s` | 高度占画高多少：**主角 0.5～0.85**，配角 0.15～0.3，远处的小东西 0.08～0.12 |
| `id` / `on` | 给插图起个名字；别的东西写 `on: "cam"`，它的 `x`、`y`、`to`、`ray` 的点、`go` 的终点就用这幅插图**自己的坐标**（svg 的 viewBox；图片、表情按 0～1）：标签指着小孔、小狗待在屏幕里、光线穿过小孔，画框变了也不会偏 |
| `delay` | 出现的秒数（从这幅画出现算起）；`fade` 淡入几秒 |
| `cue` | **按句出现**：演变那一步的配音拆成几句时（第七节），第几句（0 起）说到的时候出来，`delay` 是这一句之后再晚几秒。`hideCue` + `hideDelay`：第几句时消失 |
| `when` | **按词出现（5.11，首选）**：`"when": "小孔"` = 配音说到“小孔”这两个字的时候出来（第十二节），`delay` 是说到之后再晚几秒。同样的还有 `goWhen`（说到这个词才开始走）、`growWhen`（才开始变大变小）、`hideWhen`（才消失）。几句里都有这个词时，加 `cue` 指明是第几句 |
| `hide` | 第几秒消失 |
| `go: [x2, y2]` | 走到哪儿；`dur` 走几秒，`wait` 出现后等几秒再走（默认 0.35），`goCue` + `goDelay` 按句开始走，`arc` 走弧线，`loop` 来回 |
| `path` | `[[秒, x, y], …]` 一段一段走 |
| `s2` | 边走边变大小（跟着 go）；或者 `grow: [开始秒, 结束秒]`、`growCue` + `growDelay` + `growDur` 按句变 |
| `anim` | `bob` 上下（表情默认）、`ride` 颠、`pulse`、`spin`、`shake`、`swing` 摇（监控摄像头扫来扫去）、`click` 按快门一沉（配 `at` 秒）、`none`（插图默认不动） |
| `blink` | 一亮一灭的周期（秒）：录像的红点 |
| `shadow` | 放在桌上、地上的东西，下面一片柔和的影子（特写的主角都加） |
| `pop` | 出现时弹一下（表情默认弹，插图默认淡入） |
| `flip` / `flipY` / `rot` | 左右翻、上下翻、转多少度 |
| `reveal` | `down` / `up` / `left` / `right`：从一边慢慢露出来（`rdur` 秒） |
| `say` / `sayAt` | 头上冒一个说话的气泡（"Click!"） |
| `z` / `a` | 前后（大的盖在上面）/ 透明度 |

## 四、背景

| `bg` | 样子 | 用在 |
|---|---|---|
| `studio` | 摄影棚：柔和渐变 + 地面的影子 | **东西特写**（照相机、杯子、书包…）：主角放中间、加 `shadow` |
| `blank` | 干净的白纸 | 示意图（自己的 svg 画满整幅） |
| `sky` / `park` | 蓝天草地 / 加树和小花 | 室外；地面 y ≈ 0.76～0.78 |
| `road` / `city` / `bridge` / `sea` / `snow` / `night` / `space` | 马路、城市、桥、海、雪、夜、太空 | 地方、交通 |
| `room` / `kitchen` / `classroom` | 屋里、厨房桌面、教室 | 室内 |
| `plain` | 渐变加彩色小圆点 | 实在没有具体场景时 |

## 五、东西怎么摆、怎么动

- 一幅画只讲一件事：**一个主角**（就是讲的那样东西）+ 一两个说明它的（拍出来的照片、屏幕里的画面）+ 最多一个点缀。
- 主角在中间偏左一点，`s` 0.6～0.8；说明它的放右边，可以盖住主角一点点（`z` 大一点）。
- 站在地上的：`y` = 地面高度 − 高度 / 2；表情多半朝左，往右走的加 `flip`（6.18 起走路、跑步的小人 🚶🏃🚴 往右走、又没写 flip 的会自动翻过来；不想翻写 `"flip": false`）。
- 动作要演出“这个意思”：照相机——快门一沉（`click`）+ 闪光（`flash`）+ 照片出来；摄像机——屏幕里有东西在动 + 红点闪；监控摄像头——摇来摇去 + 一片光扫过门口。

## 六、写实插图（svg）怎么画

每个词的插图放在 `~/wordfilm-work/<单词>/art/`，prefs 里写 `"svg": "art/xxx.svg"`。画完**一定先看一遍**：

```bash
python3 <技能目录>/scripts/artsheet.py ~/wordfilm-work/camera/art/*.svg --out ~/wordfilm-work/camera/art.png   # 用 view 看
```

- 根元素写 `viewBox="0 0 宽 高"`（从 0 0 开始，`on` 的坐标才对），宽高比照东西的样子；不用写 width / height（会自动补）。
- 一个 svg 画一样东西，**背景透明**（背景交给 `bg`）；示意图例外，见第七节。
- 写实：每个面用渐变（上亮下暗），加一两块白色半透明高光、一条细亮边；镜头、玻璃用径向渐变 + 反光点；皮纹、木纹用 `pattern` 或几条淡线。参考 `example-camera/art/` 的照相机、摄像机、木盒相机。
- 不写品牌名、不画真实商标；不用 `foreignObject`、外部图片、外部字体（画到画布上会失败）；字少写，标签交给 `label`。
- 东西的比例、结构要对：照相机镜头在正面中间、快门在右上；摄像机镜头朝前、屏幕在侧面；监控摄像头装在墙上、往下看。
- 几何关系要真（光线直走、像倒立并按比例缩小）：用 Python 算好坐标再写 svg，别凭感觉摆。

## 七、示意图：讲道理的那几步一定要演出来

演变链里讲“为什么会这样变”的那一步（camera：不透光的屋子，小孔把屋外景物映在墙上），学生光听不懂，**必须配示意图并且动起来**。做法：

1. **配音拆成几句**（`flow[k].say` 写成数组），每一句讲一件事：
   ```json
   "say": ["以前，人们做过一种不透光的屋子。", "墙上开一个小孔，屋外的景物就倒着映在对面的墙上。", "这种屋子叫 camera obscura，意思是暗的屋子，后来就简称 camera。"]
   ```
2. **示意图分图层**：底图（屋外的树 + 剖开的暗室 + 小孔）一个 svg，倒立的像另一个 svg，两个 viewBox 一样大、`x`、`y`、`s` 一样，叠在一起正好对齐；光线、标签写 `on: "底图的 id"`，用底图的坐标。
3. **按词出东西**（5.11 起首选，第十二节）：`when: "不透光"` 标“暗室：不透光”；`when: "小孔"` 小孔亮、标“小孔”；`when: "屋外的景物"` 两道光线穿过小孔；`when: "倒着映"` 倒着的像淡入、标“倒着的像”；`when: "camera obscura"` 出“camera obscura：黑屋子”。
   （5.0 的写法是按句 `cue: 1` 再手调 `delay` 1.3、2.7：配音快慢一变就对不上，现在不用猜秒数了。只想“这一句一开始就出来”的照旧写 `cue`。）
4. 变小、变成别的东西：`s2` + `growCue`（暗室缩小）、`hideCue`（缩完消失）、下一样东西同一位置淡入（木盒相机），再 `goCue` 挪开、照片从盒子里出来。
5. 一步讲规律、举例子（三句：规律 / 熟悉的例子 / 本词）：规律那一句把规律的几个要点做成标签，说到哪个出哪个（“东西换了代”“干的还是那件事”“旧名字接着用”）；
   例子那一句就画例子，一左一右加个箭头（☎️ phone 电话 → 📱 phone 手机），说到“电话”出电话、说到“手机”出手机；讲回本词那一句，前两句的东西用 `hideCue` 收掉，换成本词的画（照相机 → 摄像机）。
   熟悉的例子要和本词是同一回事（都是“东西换了代”），不要随手拿一个不相干的例子。

## 八、几种常用画法

- **东西**（camera、bag、cup、computer）：`studio` 背景，主角写实插图放大到 0.6～0.8、加 `shadow`，旁边放一样说明它用途的东西（照片、书、画面）。
- **地方**（library、museum、kitchen）：自己画那个地方的样子（`img` 铺满或者 svg），再加一两个说明用途的东西；不要只放一个小图标。
- **动作**（transport、send、take a photo）：做动作的东西（车、相机）放大，起点、终点画清楚；动作做完时（三四秒）结果要看得见（货到了、照片出来了）。
- **人和职业**（teacher、driver）：画他的工具和地方（讲台、黑板 / 方向盘、公交车），要人就用全身的人，不用头像表情。
- **抽象的意思**（information、freedom）：找一个具体的场景演出来；实在画不出，用标签把关键词写出来，配一两个说明的东西。
- **原理、过程**（camera obscura、photosynthesis）：示意图（第七节）。
- **拼起来那一格**（comboPic，5.1 起）：画字面意思，不要用现在意思的画（explore 的“（向外）大声喊出来”画猎人吆喝、鸟兽被轰出来，不画探险）；没写 comboPic 就用第一幅，要看合不合适。
- **卡片左边的图**：要和这一部分的配音一致（stat 讲 stand 就用 🧍，-ion 讲“变成名词”就用“名词”牌子）；自动配得不对，在 prefs 的 icons 里写 `"p1": "🧍"`。

## 九、例句和它的动画

例句那一幕：上面一幅大动画（1120 × 432），下面英文（本词标黄）和中文；配音先念英文再念中文。
- 例句：初中生学过的词、十个词以内，最好用到总表例句列给的搭配（a security camera）；主语、动作、地点要画得出来。
- 动画把这句话演一遍，念完英文（三四秒）主要动作做完：I took a photo with my new camera → 侧面的相机对着小狗，“Click!”、闪光，照片飞出来、照片里是那只小狗；There is a security camera at the door → 房子正面（`img` 铺满），门边墙上装着监控摄像头，一片光扫过门口，红灯闪。
- 画很宽，主角照样要大（`s` 0.4～0.6）。

## 十、检查

- 起草时打印“还要补”：表情人头、主角太小、来历没配画、演变哪一步没有示意图，都会列出来，改到“都齐了”。
- `preview.png` 每一幕一张（截在快结束时）；动画中间的样子用 `snap.py` 截：
  ```bash
  python3 <技能目录>/scripts/snap.py --details ~/wordfilm-work/details.json --word camera --prefs ~/wordfilm-work/camera/prefs.json \
      --at syl:1.5,origin:2.5,evolve:30%,evolve:60%,example0:2.5 --out ~/wordfilm-work/camera/snap.png
  ```
  配好音以后加 `--plan …/plan.json --manifest …/audio/manifest.json`，按真实的配音时间截（演变那一幕按句出的东西要这样看）。
- 看这几样：**这一句配音说的东西，画面上是不是正好有**；主角是不是一眼就看得出、够不够大；有没有人头表情；标签、指示线指得对不对；光线是不是直的、穿没穿过小孔；字有没有被挡住。

## 十一、人物要和讲的人对得上（5.2 起）

用户看 explore：配音说“据说，古罗马的猎人一边走，一边大声吆喝”，画面上却是穿 T 恤的现代人（🚶），👀 还落在了他脸上。**配音说到什么时代、什么身份的人，画里就画那样的人**：
- 表情里的人（🧍🚶🏃）都是现代人的样子，只能用在现代的场景（例句里的学生、朋友）。
- 说到古代、外国、某种职业的人，自己画 svg，靠这几样一眼认出来：衣服（古罗马：短袍、腰带、斗篷和别针）、发型（短卷发）、鞋（绑带凉鞋）、拿的东西（猎人拿猎矛、带猎狗；画家拿画笔、画板；士兵拿盾和剑）、颜色（红袍金边）。
- 人要正在做配音说的那件事：说“一边走一边大声吆喝”，就画走着、手拢在嘴边、嘴张开，声波从嘴边出去；声波用 `on` 挂在人身上，人走声波跟着走。
- 别的表情不要盖住人的脸（这一版 👀 正好落在猎人头上，改成林子上方一个“?”）。
- 现成的角色在 `references/characters/`（roman-hunter.svg：古罗马猎人，朝右、手拢在嘴边喊、拿猎矛），复制到这个词的 art/ 里用；画了新的角色也放进去，以后的词接着用。
- 起草时自动查（draft_plan.js 的 `eraCheck`）：演变某一步、例句的配音里有“古罗马、古代、猎人、士兵、国王……”，画里却用了现代人的表情，列进“还要补”。

## 十二、说到哪个词，出哪样东西（when，5.11 起）

用户：“讲解的文字要和图片能完美匹配上”。以前按句出（`cue`）再手调 `delay`，一句话十来个字、三四秒，东西出早了出晚了都对不上。现在直接写**词**：

```json
{"say": ["墙上开一个小孔，屋外的景物就倒着映在对面的墙上。"],
 "fig": {"items": [
   {"shape": "circle", "on": "b", "x": 780, "y": 560, "r": 0.02, "fill": "#FFF6C8", "glow": 2.2, "when": "小孔"},
   {"ray": [[150, 444], [780, 560], [1120, 622.6]], "on": "b", "when": "屋外的景物", "dur": 1.1},
   {"svg": "art/obscura-image.svg", "x": 0.5, "y": 0.5, "s": 1, "when": "倒着映", "fade": 0.7}]}}
```

- 时间怎么算：在这一步的几句话里找到这个词，按它在那一句里的位置（中文一个字一份，英文单词按长短折算）和那一句**真实配音**的长短算出秒数，再提前 0.12 秒。配音重新合成、语速变了，自动跟着变。
- 写哪个词：这样东西的名字（“小孔”“车票”“鸭妈妈”），或者引出它的那几个字（“倒着映”“越做越小”）。要和 `say` 里的字一模一样（标点也算）；英文例句里写英文（`"when": "produces"`），中文那一句写中文。
- 一个词在几句里都出现：加 `cue` 指明第几句（`{"cue": 2, "when": "后来"}`）。
- 配套的：`goWhen`（说到才走：手拿着车票往前递）、`growWhen`（说到才变：暗室“越做越小”）、`hideWhen`（说到就收：标“暗箱”说到“有了照相技术”时收掉）。
- 一句说完整幅换内容：上一句的东西写 `hideCue: 下一句的序号`。
- 用在哪儿：演变每一步的 `fig`、例句动画 `exPic`（两句：英文、中文）、每部分卡片的画 `partPics`（句子是这一部分的配音：讲这一部分 / 在这里写成… / 记法 / 音变）。

## 十三、每部分卡片的画（partPics，5.11 起）

拆开讲的词，每部分一张卡片，左边一幅会动的图。前缀、后缀自动配的方向小动画（小人、箭头、“里 / 外”）一般够用；**词根要自己画**——尤其是有记法的：
记法说“duc 长得像 duck：鸭妈妈走在前面，领着一队小鸭子走”，左边就画鸭妈妈领着三只小鸭往前走，这样“领着走”这个意思和记法是同一幅画。

```json
"partPics": {"p1": {"bg": "park", "items": [
  {"svg": "art/duck.svg", "x": 0.56, "y": 0.53, "s": 0.46, "go": [0.78, 0.53], "dur": 16, "wait": 0, "anim": "ride", "z": 3},
  {"svg": "art/duckling.svg", "x": 0.27, "y": 0.65, "s": 0.21, "go": [0.49, 0.65], "dur": 16, "wait": 0, "anim": "ride", "delay": 0.15},
  {"label": "领着走", "x": 0.5, "y": 0.12, "size": 0.1, "when": "领着走"},
  {"label": "duck 鸭子", "x": 0.72, "y": 0.9, "size": 0.085, "when": "duck"}]}},
"icons": {"p1": "🦆"}
```

- 画的是词根的意思（领着走），不是整个单词的意思；主角同样要占画高一半左右。
- 标签用 `when` 对上配音：“领着走”在第一句（“词根是 duc……意思是：领着走”），“duck”在记法那一句。
- 卡片右边自己会按句出东西（“= 词根 duc”、字母变化、记框、音变），左边的画不用每一句都有新东西。
- `icons: {"p1": "🦆"}`：拼起来那一格里这一部分的小图标，换成和画一致的。
- 同一个词根的词用同一幅画（produce、product、introduce 都是鸭妈妈），学生看几次就记住了。现成的在 `references/characters/`（duck.svg、duckling.svg）。

## 十四、同义词辨析的画（distinguish.pics，6.0 起）

每个词一张卡，卡片上面一条横着的画：画的是**这个词说的那样东西**，两张卡放在一起一眼看得出不一样（produce：草地上一篮蔬菜水果；product：摄影棚里一只包装好的盒子、旁边一个价签）。
- 画框很扁（宽是高的三四倍）：主角放正中、别太高；背景用简单的（`park`、`studio`、`sky`），不要放一堆小东西。
- 本词的卡不用另画：自动用 `pics` 里意思对得上的那一幅。别的词的画写在 `distinguish.pics`，插图放在这个词的 `art/` 里（可以从那个词自己的视频里拷过来）。
- 这一幕不写 `when`：讲到哪个词，哪张卡整张出来。

## 嘴的剖面图（6.6，音变的原因那一幕）

`mouth(ctx, x, y, 宽, 高, 音, 本地时间, 颜色, view)`：朝右的剖面，脸的侧影、上腭（描一道浅色线）、软腭、喉咙、舌头、上下门牙、嘴唇。每个音的动作在 `YB`：
部位 lip（双唇）/ lab（下唇贴上牙）/ tip（舌尖顶上牙床）/ dent（舌尖在上下牙中间）/ back（舌根对软腭）；stop 堵住 1 秒再放开（小线一炸，一股气冲出嘴），没有 stop 的气从缝里一串串擦出来；
voice 喉咙前面弧线一跳一跳，asp 放开后嘴前一团气。`view`：'front' 只画嘴前半截、放大（p、f、t、th），'full' 整个剖面。新加别的音变，先在 `YB`、`YB_AT` 里补这个音，再用 mouthDiagram 画一张对一对（wordfilm.js 导出了 `mouthDiagram`）。


## 十四、辨析的演示（6.7）

prefs 的 `demo`：`{"preschool": {"icons": ["⏪", "🏫"], "pic": {画}, "lit": "上学以前的"}, "hard": false}`。键是演示词（总表辨析里那个用法括号的第一个例词）。
`icons` 是等式里每一部分的小图（照等式的先后），`pic` 是等号右边的画（小框，约 150 × 110，主角放大、一两样东西就够，写实插图 `svg` 也行），`lit` 不写就用组合列第一行引号里的字面意思。
画要画出字面意思（preschool：上学以前——小熊玩具和学校；forehead：头的前部——额头那一块描黄），不要单个人头表情。

## 十五、画成现实生活里的样子（6.20 起，所有的词都要这样）

用户看了 speaker 的新画：“现在的要好一些，就是要接近真实的样子，不要太抽象，不要只画一个人头，一个摆件这样的；要尽量体现出现实生活中的样子。要注意不光只是这一个单词，所有的单词都要是这样的”。

**一幅画 = 一个生活场面**，三样都要有：

## 十六、图画书画风、中外结合（6.22 起，所有的词都要这样）

用户给了一本图画书《七颗宝石》（`最新工作版/画面素材/七颗宝石 修复.pdf`）：“我希望画面的风格，色彩，线条是这样的”；看了试样以后：“把 39 页的画风保留下来再加上写实”“人物，环境，建筑，物件这些要中国和欧美相结合，不要全是中国人，也不要全是外国人；要中外相结合，各个元素相结合”。

**画风**（学画法，不照描书里的人物和画面——那本书是出版过的作品）：
- **黑色勾线**：每样东西都有墨线（`#1B1A1F`），外轮廓粗、里面的细节细，每样东西的粗细略有不同，像手画的；眼睛、头发这类用 `taper()` 画头尾细、中间粗的一笔。
- **饱和的平涂色块**：玫红、柠檬黄、翠绿、湖蓝、钴蓝、橙、紫，红配绿、黄配紫、橙配蓝；平涂，最多一层柔和渐变；不画写实的高光、明暗。
- **人物**：白净的鹅蛋脸、细长的弯月眼（眼尾上挑、下面一小块黑眼珠）、一点红的小嘴、两颊粉色圆腮红、整块头发留几道白线；外面一圈淡蓝光晕（`bkGlow`），从背景里跳出来。
- **场景照旧详细、具体**（规矩 47 的清单）：画法换成勾线平涂，不变成书里那种大片留白。

**怎么做**（`scripts/bookstyle.py`）：
- 人物：`python3 scripts/bookstyle.py people <词>/art` 生成一套（`CAST`）；要别的人 `from bookstyle import person`，`person(sex, hair='black'/'blond'/'brown'/'red', style='bun'/'pony'/'long'/'curly'/'short'/'afro', skin='pale'/'warm'/'tan'/'brown', top, collar, sleeve, gesture='raise'/'down', mouth='open'/'smile', eyes='open'/'down', freckles, glasses, tie, beard)`。位置和以前的写实人物一样（viewBox 0 0 400 560，嘴 y≈192，胸口 y≈332），讲台一组、书桌一组照样用。
- 场景、东西：先照第十五节画详细的写实原图（`python3 scripts/scenes.py raw/` 生成四张背景和课桌、横幅），再转成图画书画风：`python3 scripts/bookstyle.py stylize raw/station-bg.svg art/station-bg.svg --bg`（背景加 `--bg`；单件东西不加）——加墨线、颜色调饱和、去掉写实高光。`references/scenes/` 里的已经转好了，直接拷。

**中外结合**：
- **人**：一个词的画里中国人和欧美人都要有。文件名前缀标出来：`cn-…`（中国人：梳发髻的女老师、男生、扎马尾的女生）、`west-…`（欧美人：留胡子的西装男士、红色卷发有雀斑的女孩、金发女士、黑人男孩、戴眼镜的职员）。安排要自然：中国的教室里中国老师教外国学生，舞台上外国嘉宾演讲，车站里中外旅客都有；人群（听众、旅客）里黑发、金发、棕发、红发、不同肤色都有。
- **环境、建筑、物件**：中式和西式的东西放在一起，或者一个词里有的场景是中国的、有的是外国的。屋里是西式的书架、地球仪、相框，加中式的山水画（红印章）、青花瓷瓶、中国结；舞台横幅中英双语（“校园英语演讲比赛 ENGLISH SPEECH CONTEST”，`banner(中文, 文件名, en=英文)`）；车站是中国的火车站，旅客中外都有。以后的词也这样：街上中式的店招和西式的咖啡馆、中国的公园和欧洲的广场、筷子和刀叉……
- 起草时 draft_plan.js 查：人物只有 cn- 或只有 west-；还用着写实的旧人物（teacher-talk.svg、clerk.svg……）；场景背景还是写实画法（没有墨线）。都列进“还要补”。

## 十七、动作、表情要变，可以做动图（6.24 起）

用户看了第六十版的 speaker：“人物的动作，表情很单一，几个画面都是一样，姿势，手势都一样，我希望表情，动作，姿势不同画面，场景要做适当切换，要有改变，不要前后都一样；也可以做一些动图，不一定都要静态的图”。

- **每幅画的人换一个动作和表情**，照这一句配音在说什么来定：讲课的老师指着黑板说；听的人歪着头微笑；被逗乐的哈哈笑；举手发言；两手摊开讲解；指着屏幕；托着下巴想；听音乐笑眯眯地竖大拇指。同一个人在一个视频里出现几次，动作、表情都不重样。
- **画法**（`scripts/poses.py`）：`pose(...)` 在图画书人物上加动作和表情——
  - 胳膊是两节“管子”（肩 → 肘 → 腕），`left` / `right` 写 `ARM` 里的名字：`down` 垂着、`hello` 举手打招呼、`wave1` / `wave2` 挥手两帧、`point` 往旁边指、`pointup` 往斜上方指、`present` / `presentHi` 两手摊开（站在讲台后面用 presentHi，手举得高、看得见）、`chin` 托下巴、`thumb` 竖大拇指、`raise` 举手发言、`chest` 手放胸前；也可以自己写 `(上臂角度, 上臂长, 前臂角度, 前臂长, 手)`，角度从“垂直往下”算、往外为正，手有 `open`、`point`、`fist`、`thumb`、`none`。
  - 表情：`eyes` = open 弯月眼 / happy 笑眯眯 / wide 睁大 / closed 闭眼，`look` = -1 / 0 / 1 往哪边看；`brows` = normal / up 扬起 / frown 皱 / one 一边挑；`mouth` = smile / open 说话 / half 半张 / laugh 大笑 / o 吃惊 / flat 抿嘴；`tilt` 歪头几度；`blush` 腮红大小。
  - 长相在 `LOOKS`（cn-teacher、cn-boy、cn-girl、west-man、west-girl、west-woman、west-boy、west-clerk），动作在 `ACTIONS`（`cn-teacher-point`、`west-girl-music`……）；`python3 scripts/poses.py <词>/art` 生成一套，现成的在 `references/characters/poses/`。画布是 0 0 720 560（左右各留 160 给伸出去的胳膊），人在中间：嘴在 (360, 192)、胸口 y≈332，声波 `waves.svg` 挂在人身上写 `"on": "人的 id", "x": 452, "y": 186`。
- **动图**：一个动作写几帧（`ACTIONS` 里一个列表），生成 `名字_f0.svg`、`名字_f1.svg`……；prefs 里这一样写 `"frames": ["art/名字_f0.svg", "art/名字_f1.svg"], "fps": 3`（`svg` 写第一帧），从出现那一刻起按 fps 轮着放。常用的：说话（嘴一张一合，两帧，fps 3）、挥手（wave1 / wave2）、跟着音乐摇头（头往左歪 / 正 / 往右歪，四帧，fps 2.5）。example-speaker 的 `actor(名字, fps)` 有几帧就自动做成动图。
- 起草时 draft_plan.js 查：同一张人物图用在三幅以上的画里；有人物却一个动图都没有。都列进“还要补”。


## 十八、画面动起来、有互动（6.25 起，所有的词都要这样）

用户：“我希望图片里面要有适当的动图，比如 speaker画的是人在演讲，那么可以让人物动起来，嘴巴讲起来这样的；大喇叭也是一样，可以画一下音波这样的，周围有人的画，可以画人在走动。总之要是动态的图”“如果多人同台，或者做事，要增加一些互动，就是人和人，人和物，物和物 这些之间有的时候可以增加一些互动，要根据内容来进行”。

**先生成会动的人**：`python3 scripts/poses.py ~/wordfilm-work/<单词>/art --motion` → `<动作>_m00.svg…`、`walk-…_w0.svg…`、`motions.json`。要新的动作，在 `poses.py` 的 `MOTIONS` 加一条（`kind: talk` 写两三个关键手势 `keys`，`blink` 写慢慢动的几个样子，`pingpong` / `loop` 直接写几帧），要新的走路的人在 `WALKERS` 加。

**画里一样东西怎么动**（prefs 的 items 里写）：

| 写法 | 用在哪儿 |
|---|---|
| `frames` + `seq: "talk"`、`mouths: 3`、`gfps`、`mfps` | 说话的人：手势来回慢慢动，嘴一张一合、一句一停（`phrase` 一句几秒） |
| `seq: "blink"`、`fps` | 听、想的人：慢慢歪头 / 眼睛往两边看，隔三秒左右眨一下眼 |
| `seq: "pingpong"` / `"loop"`、`fps` | 笑、挥手、跟着音乐摇头 |
| `turn: [0, 2]`、`[1, 2]`，`turnLen` | 两个人轮流：说话的只在自己那一轮说（轮到别人时边听边点头），笑的人在对方说完才笑 |
| `talkWhen: "讲话"` / `talkUntil` | 配音说到这个词才开口 / 说到这个词闭嘴 |
| `nodWith: "m"` | 听的人：id 为 m 的人每说完一句，点一下头 |
| `walk: {from: [x, y], to: [x, y], offset}` | 走路的人：一直走，走出画再从头进来；往左走自动翻过来；不写 speed 就按步子大小算 |
| `anim: "breathe"` / `"thump"` / `"step"` / `"sway"` / `"nod"` | 人轻轻起伏（会动的人默认就有）/ 音箱跟着拍子鼓 / 走路一颠 / 摇摆 / 点头 |
| `crowd: 9`、`nodWith` | 一排人（台下听众）：切成几个人各自轻轻动，台上的人说完一句大家点头 |

**四样效果**（一样东西写了就按效果画，不用图）：

| 写法 | 画什么 |
|---|---|
| `waves: true`，`x`、`y`（可以 `on` 一张插图）、`dir`（0 右、90 下、180 左）、`spread`、`n`、`period`、`r0`、`r1`、`color`、`lw`、`with`、`both` | 一圈圈往外走的声波；`with: "man"` 那个人说话时才出（人和物：人对着麦克风说、喇叭才响） |
| `emit: true`，`svg`（`alt` 再几张）、`every`、`life`、`to: [dx, dy]`、`s`、`wobble`、`spin`、`offset`、`with` | 一个接一个飘出来的东西：音符、水滴、气泡；画写了 `beat` 时默认每两拍一个 |
| `eq: true`，`x`、`y`、`w`、`h`、`n` | 屏幕上跳动的柱子（放音乐）；跟着 `beat` 跳 |
| `beam: true`，`x`、`y`、`len`、`width`、`swing`、`period`、`tilt` | 舞台的光柱，慢慢左右摆 |

**一幅画的节拍**：画写 `"beat": 100`（每分钟 100 拍），音箱的 `thump`、音符的 `emit`、`eq` 都踩它；跟着音乐摇头的人 `fps` 写 `beat / 60 × 2`（两拍一个来回），物和物、人和物就对上了。

**按内容加互动的几种常见的**（speaker 样例都用到了）：
- 讲课、演讲：说话的人 `seq: talk`，听的人 `nodWith` 他，嘴边 / 麦克风出 `waves`（`with` 他），台下 `crowd` + `nodWith`；舞台加 `beams`。
- 对话：两个人 `turn` 轮流说；一个讲、一个笑（笑的那个也写 `turn`，讲完才笑）。`turn` 一轮默认 2.6 秒，只适合停得久的画（例句、意思）；只出现一两秒的画（演变第一框只在“它们是怎么来的呢？”那一句）用不上轮流，两个人同时动（一个说、一个笑 / 点头）。
- 放音乐：电脑屏幕 `eq`、两边音箱 `thump` + 外侧 `waves` + 音符 `emit`，听的人跟着拍子点头。
- 车站、街上、商场、公园：`walk` 几个走路的人（中外都有、往两边走、远的小近的大、`offset` 错开），广播喇叭两边出 `waves`。
- 人指着东西讲：东西跟着动（屏幕上的水龙头一直滴水 `go` + `loop`，图表一条条长出来……）。

**大小**：辨析卡片两张时画是 504 × 204（6.25 放大），写辨析的画时 `W, H = 504, 204`；背景用 `band()` 挑露出哪一条。走路的人在这么大的画里 `s` 0.42～0.56 看得清。


## 十九、音效（6.28 起，规矩 56）

用户：“可以做一些音效，比如讲车子，可以有车子跑的声音，当然不要太长，不要影响主要的讲解，只是加深一下学生学习的印象；演讲也可以来一句演讲，扬声器也可以播放一下声音等等”。

| 写法 | 什么时候响 |
|---|---|
| 画里一样东西写 `"sfx": "shutter"` | 它出现的那一刻（`when` / `cue` / `delay` 算出来的时刻） |
| 单独一条 `{"sound": "meow", "when": "它"}` | 看不见、只出声；`when` 写配音里的词 |
| `"times": 2, "every": 1.0` | 响两下，隔一秒 |
| `"vol": 0.6` | 小声一点（默认 1：比讲解小 6 dB） |
| `"gap": true` / `"sound": "say:Hello, everyone!"` | 找配音停着的空当放；例句里会自动在那一句后面多停（`"wait": 2.5` 自己定多久） |

挑法：一个视频三到六个，放在最能加深印象的地方——这个词本身会出声（camera 快门、alarm 铃、speaker 音乐、loudspeaker 广播），例句里正在发生的事（猫叫、车开过去、水哗哗），演变里讲到的那一下。演讲的画可以让台上的人说一句 `say:Good morning, everyone!`，喇叭、音箱放 `dingdong`、`music`。和画面上的动静对上：铃在摇时响 `bell`，闪光时响 `shutter`。

## 二十、画里放不放人（6.28 起，规矩 57）

用户：“不是每个画面都需要有人在里面，要根据当时讲解的内容来定，如果不需要人，就可以不放人在里面”。

- **要放人**：讲人（演讲人、陌生人、外地人、主人）、人做的事（拍照、指路、调温度、照镜子）、人和人的关系。
- **不放人**：讲动物（猫舔毛）、东西本身（闹钟在响、恒温器上的数、门锁）、地方和景色（房间本身很干净、山、湖）。这时主角画大一点，让它自己动：猫一下下舔爪子、闹钟一边抖一边出声波、屋里飘亮晶晶的星星。
- 一个词里只有一两个人时，不要求中外都有；三个以上不同的人，还是要中外结合（规矩 48）。
