# speaker（6.24 标准样例：图画书画风 + 详细的生活场景 + 中外结合 + 动作表情不同、动图）

`make_prefs.py` 生成 prefs（`python3 make_prefs.py ~/wordfilm-work/edits.json`）：讲台一组（`stage_group`）、书桌一组（`desk_scene`）、音符和声波（`notes_from`）、扁画框的背景（`band`）的位置都是算出来的，别的词照着改。
`art/` 是这个词用到的全部插图（从 `../scenes/`、`../characters/` 拷来的，加两张小图标）。
配音稿手改了两处（样例里是 `brief_plan.json`，用的时候放到 `<单词>/brief/plan.json`）：辨析三句说顺；听力那句 today's 念成 todays（避开撇号，画面上的字不变）。
