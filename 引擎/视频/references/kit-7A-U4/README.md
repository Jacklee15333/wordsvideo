# 7A-U4 这一单元的画法工具和每个词的画面设置（6.27–6.28，第六十九～七十版）

- `common.py`：写原图 → `bookstyle.py stylize` 转图画书画风（`write_art`）；人物手里拿东西（`holding`：人 + 相机 / 地图 / 手机拼成一张）；几帧动图（`frames_out`）。
- `prefkit.py`：example-speaker/make_prefs.py 里的帮手（`actor`、`walker`、`mouth_waves`、`beams`、`stage_group`、`audience`、`desk_scene`、`music_from`），外加 `band()`（扁画框露背景的哪一条）、`waist(s)`（人让画框下边截在腰上时的中心 y）。环境变量 `WART` 指向这个词的 art 文件夹；`actor` 会读 art 里的 motions.json、cam_motions.json、word_motions.json。
- `*_art.py`：每个词新画的场景和东西（camera：公园、拱顶大厅、暗室、相机、三脚架摄像机……；thermostat：恒温器、空调、暖气片、温度计、鱼缸；itself：猫、镜子、坐垫；alarm：城墙夜景、卧室、闹钟、火警铃、武器架、鼓；street_art：街道、地图）。用法：`python3 cam_art.py ~/wordfilm-work/camera/art`（先把 references/scenes/*.svg 拷进去，再 `python3 scripts/poses.py art --motion`）。
- `words/<单词>.py`：画面设置（`python3 words/itself.py ~/wordfilm-work/edits_itself.json`，再 `run.py --edits …`）。itself 是 6.28 的标准样例：画里放不放人看内容（规矩 57），五处音效（规矩 56）。

- `lock_art.py`：家门口（木门、春联、福字、门牌、花盆、信箱）、运河船闸（两岸石堤、闸门、白墙黛瓦、风车）、挂锁、钥匙（转动三帧）、门闩（插销滑进去三帧）、船、闸室水位（四帧）、抽屉。
- `tools/`：`go.sh`（前台跑一段）、`loop.sh`、`queue.sh`（后台排队、做好就传）、`expand.py`（配音里的缩写念全）、`gh_add.py`（Git Data API 只新增文件，保留仓库原有的一切）。
- 6.29：06–10 是青绿工笔风：先照图画书风画好、检查“都齐了”，再 `python3 scripts/styles.py gongbi ~/wordfilm-work/<单词>/art`。
