# 配音稿和画面设置怎么写

目录：一、一段视频有哪几幕 · 二、plan.json（配音稿）· 三、prefs.json（画面设置）· 四、核心版怎么讲（含演变链、用词规律）· 五、发音没听清怎么改 · 六、详细版 · 七、标准样例

## 一、一段视频有哪几幕

画面由 `scripts/wordfilm.js` 按词源数据和 prefs.json 生成，幕的顺序固定。plan.json 里每一幕用下面的“键”：

| 键 | 什么时候有 | 画面 |
|---|---|---|
| `title` | 总有 | 单词一个字母一个字母出现，下面按拆分画几条不同颜色的线（不能拆的词画一条黄线），上面是词源类型；下面写这段视频分的几部分“一 读音拆分 → 二 含义拆分 → 三 同义词辨析 → 四 总结”（6.0 起；有几部分写几部分） |
| `sec0` | 有读音拆分（5.0 起） | 分段标题“一 读音拆分”，叮咚一声，不说话 |
| `syl` | 有读音拆分 | 单词按音节表分块（照表的样子：红色划掉不发音、蓝色下划线固定组合、绿色读字母音、紫色特殊读音），一块一块亮起来念，下面出这一块的音标；再合成整词，写整词音标，标出重音；`marks: true`，句子数 = 念的块数 + 1（连起来）+ 1（重音，单音节没有） |
| `sylnote` | 音节表“关键解释”有字 | 上面是分好的块，下面一条一张卡，说到哪条出哪条、那几个字母标黄；`marks: true`，一条一句 |
| `sec1` | 有读音拆分 | 分段标题“二 含义拆分”，不说话；后面就是原来的几幕 |
| `split` | 能拆（拆分写成 `a + b`） | 字母按部分分开、上色 |
| `part0`、`part1`… | 能拆 | 每部分一张卡片：会动的图（`partPics` 写了就是自己画的画）+ 意思 + 小牌子（来自哪种语言 · 前缀/后缀/词根 · 词性怎么变）+ 各部分解释。5.11 起：词根的另一种写法标题后面写“= 词根 duc”、多一行“字母变化 duc → duct”；有记法的下面一个“记”框，记法带音变的框里再一行“音变 f → d”。这一部分讲了不止一句（变体、记法、音变）时 `marks: true`，说到哪句出哪块 |
| `fengong0`、`fengong1`… | 6.0 起：这一部分在总表那一行写了“身份：…。分工：…”（跟在它的 `part` 后面） | “身份和分工”：这一部分和它的身份、分工一条一条、最下面“为什么用 -ous 不用 -ful”；6.1 起词根是拉丁语动词的（总表那一行有“动词变化：…；规律：…”）中间多一条三个框“原形 → 过去式 → 过去分词”和规律；`marks: true`，句子数 = 1（身份）+ 1（有三个样子时：变化规律）+ 讲的条数（词根最多 3、词缀最多 2）+ 1（有“为什么用…”时） |
| `combo` | 能拆 | 等式：图 + 图 = 一幅画 + 字面意思 |
| `rule` | 组合列有“合成规律 / 写法”行（3.7 起，合成词、带连字符的词） | 一条规律一张卡：黄卡“★ 合成规律”、蓝卡“★ 写法”，规律那句话 + 本词的例子；`marks: true`，句子数 = 卡片数 |
| `route` | prefs 里写了 `route`（核心版只有手写了才有） | 来历：一步一步怎么变成这个词 |
| `variant` / `related` / `origin` | 变体（made ← maked）/ 同源（set ≈ sit）/ 基础词 | 字母怎么增减 / 两个词并排 / 来历卡片（左边是 originPic：画的就是来历里说的东西；没写就只写字，不再自动配表情） |
| `steps` | 详细版，“构词逻辑”里有 → 开头的几行 | 意思一步步变过来（老样式） |
| `meaning` | 有“今义”或写了 `pics` | 每个意思一幅会动的画，下面词性和一句话区别 |
| `evolve` | 写了 `flow`，或者 pics 里有 `evo` | 意思是怎么一步步变过来的：左边竖着一条链，右边一块大画板，讲到哪一步放哪一步的示意图（`fig`），见第四节；一步的 `say` 写成几句时，plan 里多一个 `groups`（每一步几句） |
| `example0`、`example1`… | `pics` 里写了 `ex` 的意思 | 例句：一段大动画演这句话，下面英文（本词标黄）、中文 |
| `family` | 详细版，有同一组号的词 | 同一词族，共同的部分标颜色 |
| `sec2`（或别的号） | 6.0 起：有第三部分 | 分段标题“三 同义词辨析”，不说话 |
| `distinguish` | 6.0 起：辨析列拼得出一组，或 prefs 里手写了 `distinguish` | 每个词一张卡 + 下面“逻辑不同”；`marks: true`，句子数 = 1（提出问题）+ 词数 + 1（有 logic / tip 时） |
| `sec3`（或别的号） | 6.0 起：分了段、有总结 | 分段标题“四 总结”，不说话 |
| `board` | prefs 里 `board` 不是 false | 总结（笔记纸）：上面单词、读（音节块 + 整词音标）、拆、意思、扩展；右上角组合图；黄框“重点”（英语用词规律）；下面每个意思一张卡（贴的画、意思、词性、例句）。视频停在这里。6.1 起一页放不下就分两页：这一幕标题写“总结 1/2”、只写字（多“变化”“辨”两行，最多 12 行） |
| `board2` | 6.1 起：总结分了两页 | “总结 2/2”：每个意思一行——左边贴画，右边意思（带词性）、例句、中文。不配音，视频停在这里 |

核心版（默认）没有 `steps`、`family`，`route` 要手写了才有；`split`、`board`、`board2` 和各个 `sec` 不配音，plan.json 里没有这几个键（按默认长度放：一页的总结 9 秒起，内容多会自动加长；分两页时第一页 4.6 秒 + 每行 0.55 秒，第二页 6.4 秒 + 每个意思 1.7 秒）。
分段标题的号按这段视频实际有的部分排：没有读音拆分、没有同义词辨析的词，`sec` 的个数和号跟着少（introduce 没有能比的词：`sec0` 读音拆分、`sec1` 含义拆分、`sec2` 总结）。

## 二、plan.json（配音稿）

```json
{
  "word": "transport", "voice": 38, "speed": 0.95, "style": "core",
  "scenes": {
    "title":    { "segs": ["transport：运输、运送。"] },
    "part0":    { "segs": ["前缀是 trans，来自拉丁语，意思是：到另一边。"] },
    "part1":    { "segs": ["词根是 port，来自拉丁语，意思是：搬运。"] },
    "combo":    { "segs": ["合起来，就是搬到另一边。"] },
    "meaning":  { "marks": true, "intro": "现在有两个意思：", "segs": ["一是运输、运送，", "二是交通运输。"] },
    "evolve":   { "marks": true, "intro": "它们是怎么来的呢？", "segs": ["……", "……", "……", "……"] },
    "example0": { "marks": true, "segs": ["Trucks transport goods to the city.", "卡车把货物运到城里。"] },
    "example1": { "marks": true, "segs": ["I go to school by public transport.", "我坐公共交通去上学。"] }
  }
}
```

- `segs`：这一幕按顺序念的句子。一幕的长短 = 这几句念完的时间（开头空 0.45 秒、句间 0.32 秒、末尾 0.7 秒）。
- `marks: true`：画面上的项目“说到才出现”，**句子数要和项目数一样**：`meaning` 是画的幅数；`evolve` 是链上除第一框以外的框数（每说一句，出一个箭头、说明和框）；`example` 是英文一句、中文一句；详细版的 `combo` 是部分个数 + 1，`route` 是来历步数，`steps` 是变化步数。开场白放 `intro`，不算一项。对不上时画面自己按顺序出来，不会出错。
- 一句也可以写成 `{"t": "qzca", "speed": 0.85}`：这一句单独的语速（读音拆分念每一块用 0.85）。
- `lexicon`（5.0 起）：临时加进配音模型词典的词，`{"qzca": "k ˈ æ", "obscura": "ɒ b s k j ˈ ʊ ə ɹ ə"}`（Kokoro 的音素，空格隔开）。读音拆分的“音素词”（qz 开头，念出来正好是这一块的音，me 念 /mə/ 不会念成 /miː/）由起草自动写；词典里没有的生词在 prefs 的 `lexicon` 里加，起草时并进来。只有音素词的句子剪掉前后空白、不用语音识别检查；整词的音素词（qzcamera）按 camera 检查。
- `groups`（5.0 起）：演变那一幕一步拆成几句时，每一步几句（起草自动写）。
- `voice` / `speed`：默认 38 号女声、0.95 倍速。想换可以试 25 号（低一点、温和，英文偶尔念不准）、5 号（最清楚，语调平一些）。
- 手改过的 plan.json，run.py 不会覆盖；没手改过的（和同一文件夹的 plan.auto.json 一样）每次都按最新的画面设置重新起草。所以多数时候只改 prefs.json，配音稿跟着变。

## 三、prefs.json（画面设置）

起草时生成 `{"style": "core", "board": true}`；一批词的设置写在 `edits.json`（`{"单词": {...}}`），run.py 加 `--edits` 合并进各自的 prefs.json。

| 键 | 作用 |
|---|---|
| `style` | `core` 只讲核心 / `full` 详细版 |
| `pics` | 每个意思一幅画，最多 3 幅：背景、角色、`pos` 词性、`diff` 区别、`ex` / `exzh` 例句、`exPic` 例句动画。写法见 `pictures.md` |
| `comboPic` | 单独给“拼起来”那一格（和小黑板右上角）一幅画，默认用第一幅 |
| `partPics` | 5.11：每部分卡片左边自己的画，`{"p1": {…}}`（写法同 pics；词根有记法的一定要画，见 `pictures.md` 第十三节）；配套 `icons: {"p1": "🦆"}` 换掉拼起来那一格里的小图标 |
| `flow` | 意思怎么一步步变过来的那条链，见第四节 |
| `rules` | 不在演变链里的用词规律，也写上小黑板“重点”：`[{"text": "……", "ex": "……"}]` |
| `extend` | 小黑板“扩展”那一行的词，比如 `["import", "export", "support", "translate"]`；**只能用词源总表里的词**（run.py 核对，会补上意思）。`false` 表示不要 |
| `from` / `role` | 改某个部分的来源、作用：`{"p1": "拉丁语"}`、`{"p1": "加在动词后面，把动作变成名词"}` |
| `skip` | 不要的几幕：`["route"]`；`"part1"` 只去掉第二张卡片 |
| `text` / `icons` | 改卡片上的字、图（表情）：`{"p0": "传达、交流", "combo": "传达这件事", "final": "交流、沟通"}`、`{"p0": "📨"}` |
| `route` | 自己写来历：`[{"text": "com + mun", "gloss": "一起 + 大家分担的那一份", "icon": "🤝"}, …]` |
| `familyWords` / `familyShared` / `familyTitle` | 详细版“同一词族”那一幕（词也要在总表里） |
| `board` | `true` 自动写；`{"combo": false}` 不要右上角组合图，`{"cards": false}` 不要例句卡，`{"rules": false}` 不要重点框，`{"note": "…"}` 写一句提示（默认不写；只写字的一页写在最后一行下面，分两页时写在第二页右上角）；也可以整块手写 `{"lines": [...]}`，扩展词那行写 `{"extend": true}`、重点写 `{"rules": true}` 让它自动填。6.1：`{"pages": 1}` 硬性放一页、`{"pages": 2}` 硬性分两页（默认自动：下面例句卡那一块不够高就分两页；卡片上一个例句都没有时不贴卡片、不分页）；`{"verb": false}` 第一页不写“变化”那一行，`{"dist": false}` 不写“辨” |
| `pace` | 没配音时整体快慢（0.8 慢一点，1.25 快一点） |
| `compRules` | `false`：不要“合成规律”那一幕，小黑板也不写合成规律（3.7 起，默认要） |
| `distinguish` | 6.0：第三部分“同义词辨析”。不写：照总表辨析列自动拼（拼不出来就没有这一部分）。`{"pics": {"product": {画}}}`：给别的词的卡配画（本词的卡自动用它那个意思的画，也可以在这里写本词）；`"logic": "…"` / `"tip": "…"`：最后一句（逻辑差在哪儿 / 一句话记法）。整段手写：`{"key": "产品", "items": [{"w": "produce", "gloss": "农产品", "note": "地里长出来的蔬菜、水果，是一大类东西，不可数", "ex": "fresh produce 新鲜农产品", "literal": "领到前面来", "pic": {画}}, {"w": "product", …}], "logic": "…"}`（2～3 个词）。`false`：不要这一部分 |
| `fengong` | 6.0：“身份和分工”那一幕。默认总表写了分工的部分都讲；`{"p0": false}` 这一部分不讲，`false` 都不讲 |

手写小黑板时，每行 `{"label": "拆", "segs": [["trans", "b"], [" + ", "f"], ["port", "o"]]}`；第一行一般不写 label、字大一点：`{"size": 66, "segs": [["transport", "y"], ["   运输、运送", "w", {"size": 40}]]}`；`"label": ""` 是接着上一行写；`"hl": true` 的几行用黄色粉笔框起来。粉笔色：`w` 白、`y` 黄、`b` 蓝、`o` 橙、`g` 绿、`p` 粉、`f` 淡白；各部分的颜色和前面画面一致：第一部分蓝 `b`、第二部分橙 `o`、第三部分绿 `g`。

## 四、核心版怎么讲

用户的要求：只把核心用语音讲出来，画面上的其他字不念；但意思是怎么变过来的、英语的用词规律，一定要讲清楚。

| 幕 | 说法 |
|---|---|
| 开头 | “transport：运输、运送。”（单词 + 冒号 + 意思，不说“同学们好”“今天的单词”） |
| 读音拆分 | “分成三块来读：”然后每一块念它的音（ca，me，ra），“连起来：camera。”“重音在第一块。”（全是起草自动写的；对不齐的词只念“camera。”） |
| 关键解释 | 一条一句，照音节表第三列念：字母一个个念（d u），/音标/ 换成真念出来的音，a_e 念成“a 后面隔一个辅音跟着 e” |
| 来历 | “它的来历：来自拉丁语 camera，意思是拱顶、带拱顶的屋子。”（英文后面紧跟引号的，自动在中间加“，意思是”） |
| 拆开 | 不说话 |
| 前缀 | “前缀是 trans，来自拉丁语，意思是：到另一边。”（英语本族的说“英语本来就有”） |
| 后缀 | “后缀是 -ion，来自拉丁语，加在动词后面，把动作变成名词。在这里，就把看这个动作当成一样东西来说。”（“在这里”取自总表这一行的“在这里：…加上 -ion，……”；表里没有时意思具体的再加一句“在这里意思是：……”） |
| 词根 | “词根是 port，来自拉丁语，意思是：搬运。”（来源不知道就不说） |
| 词根的另一种写法（5.11） | 总表词根列写“词根 duc 的另一种写法…字母变化：duc → duct，…”的，分两句：“词根是 duc，来自拉丁语，意思是：领着走。”“在这里写成 duct，是被领出来的。duc 后面加 t。”（第二句后半是“字母变化”里最要紧的那半句；这个词里的意思和词根的意思不一样才说“是……”） |
| 字母变化挪到“身份和分工”（6.4） | 词根的另一种写法后面有“身份和分工”那一幕的（`part.varInFg`）：卡片那一幕第二句只说“在这里写成 duce。”（意思不一样的还带“，是被领出来的”），字母怎么变的挪到“身份和分工”那一幕当第 2 句：“从 duc 到 duce：英语加不发音的 e。”“从 duc 到 duct：duc 后面加 t。”（总表没写怎么变的：“duc 在这里写成 duce。”）。后面没有那一幕的照 5.11，两样都在卡片那一幕说。 |
| 单词 | “单词是 make，英语本来就有，意思是：做。”（总表「单词部分」列里的词：基础词本身、母词、合成词里的词） |
| 记法（5.1） | 总表那一行写了“记：”的，单独一句：“记法：stat 约等于 stand 这个词，意思是站。stand 是站，stat 也是站、站住；它们本是一家。”（∽ 念“长得像”，← 念“来自”；英文后面不紧跟逗号，念得清楚）。词根和单独的词写法一样的（port ≈ port 港口）念“记法：port 单独用也是一个词，意思是港口。……” |
| 音变（5.11） | 记法后面写了“音变：”的，再单独一句：“音变：f 对 d。印欧语的 d h，拉丁语在词头念成 f，英语念成 d。”（先说谁对谁，再念那一句话；括号里的印欧语词根、别的例子不念；一两个字母、没有元音的三个字母一个一个念）。一条链的只念那一句话：“音变：夹在两个元音中间的 g 越念越轻，脱落了。” |
| 拼起来 | “合起来，就是搬到另一边。” |
| 合成规律 | 一条一句：“英语里，动词带着宾语合成一个词，宾语挪到前面，动词放在最后当主体。cut paper 剪纸，就成了 paper-cutting。”（规律那句话照总表念；例子取括号里第一段，“→”念成“就成了”） |
| 现在的意思 | 一个：“所以，transport 就是运输、运送。”几个：“现在有两个意思：一是……，二是……。” |
| 演变 | 链上每一框一句，见下 |
| 例句 | 先英文一句，再中文一句 |
| 小黑板 | 不说话 |

来源和作用来自 wordfilm.js 的 `AFFIX_PRE` / `AFFIX_SUF`（常用前缀后缀）和词族“背景”（只有一个词根时）；各部分解释里写得更具体或者不一样的，以各部分解释为准：现在起草时自动读各部分解释里的来源括号和“在这里”（`tableAffix`），个别还要改的再在 prefs 的 `from`、`role` 里改。

总表各部分解释里还有“意思怎么变：① 说明 → 结果〔用词规律①〕 ② ……”和“用词规律：① 规律（本词例子；熟悉的例子）”：演变链自动拼的时候，按“结果”对上那一步，挂上 `rule` / `ruleEx`，配音念“英语里，规律。说明，就是这个意思”；小黑板“重点”也自动写上。手写 `flow` 时可以直接抄这两行。

### 意思怎么一步步变过来（`flow`）——用户最在意这一段

学生会想：动词好好的，为什么突然多了一个名词的意思？这个意思是怎么产生的？道理不讲清楚，学生就不懂这个意思。所以每个现在的意思，都要从字面意思一步一步走过去，每一步说清为什么会这样变。

```json
"flow": [
  {"node": "“搬到另一边”"},
  {"via": "把人、货物从这儿搬到那儿", "node": "① 运输、运送", "pos": "动词", "pic": 0,
   "say": "搬到另一边，就是把人或货物从这儿运到那儿，这就是运输、运送。它说的是一个动作，所以是动词。"},
  {"via": "从动作到东西：做这件事用的东西，也叫 transport", "node": "用来运人运货的东西", "icons": "📦 🧳",
   "rule": "英语里，表示动作的词，常常也拿来叫做这件事用的东西", "ruleEx": "transport 运 → 运输工具      cover 盖 → 盖子",
   "say": "英语里，表示动作的词，常常也拿来叫做这件事用的东西。就像 cover 是盖，盖东西的盖子也叫 cover。所以，用来运人运货的东西，也叫 transport。"},
  {"via": "车、船、飞机，统称", "node": "运输工具", "icons": "🚚 🚢 ✈️", "say": "车、船、飞机，都是用来运人运货的东西，统称运输工具。"},
  {"via": "城里运人的公交车、地铁合起来", "node": "② 交通运输", "pos": "名词", "pic": 1, "icons": "🚌 🚇",
   "say": "城里每天运人的公交车、地铁合在一起，也叫 transport，就是交通运输。它说的是一样东西，所以是名词。"}
]
```

- 6.23 起画面上是思维导图式的树：第一框（字面意思）在最上面，每一框往右缩一级表示从上一级变来，`via` 写在这一框正上方（规矩 49）。
- 第一框是字面意思（拼起来那一步的结果）。后面每一框：`node` 框里的字（十个字以内）；`via` 箭头旁边的字，写**为什么**会变成下一框；`say` 这一步的配音；`pos` 词性；`pic` 这一框是第几个现在的意思（从 0 数，右边贴那幅画）；`icons` 框右边的几个小图；`from` 这一步从第几框出发（默认上一框；两个意思都直接从字面意思来时，第二个意思写 `"from": 0`，箭头从左边绕下来）。
- 材料在总表“组合 → 现在的含义”那一列：→ 开头的几行是“说明 → 结果”，【演变】是年代顺序，起草时会打印出来。transport 那一列里写着“→（n.）用来运人运货的东西 → 运输工具”，这就是动词变名词的关键一步，链上必须有。
- 中间缺的那步要补上，让每一步都是小小的一步：“运输工具”到“交通运输”中间是“城里运人的公交车、地铁合起来”。
- 一步一句，每句先说道理，再说出这一框的意思；说到现在的意思时带上词性（“它说的是一个动作，所以是动词”）。不要用“不是……而是”这种句式。
- 5.0 起：每一步配一幅示意图 `fig`（写法见 `pictures.md` 第七节），讲到这一步时右边大画板就放它；讲道理的那一步，`say` 写成几句（数组），示意图里的东西写 `when`（5.11 起，说到哪个词出哪样东西；`pictures.md` 第十二节）——配音说到“小孔”，画面上小孔正好亮起来。写法照 `example-camera/prefs.json`、`example-produce/prefs.json`。
- 5.11 起：写 `say` 的时候就想好每一句画什么——**一句只讲一件画得出来的事**，句子里要有这样东西的名字（好给 `when` 用）；一句里讲了两样东西，就让它们一先一后出来。
- 5.11 起：`from` 不是上一框的那一步（两个意思都从字面意思来），箭头旁的“为什么”写在紧挨着这一框的上方，不会再压住中间的框。
- 没写 `flow` 的，按每个意思的 `evo`（或者总表里正好写着这个意思的那一行）自动拼一条，都从字面意思出发，只能当草稿。

### 英语的用词规律（`rule`）——当重点写上小黑板

演变里有一步体现了英语的用词习惯，就在那一步写 `rule`（规律，一句话）和 `ruleEx`（两三个例子，最好有本词和一个学生熟悉、总表里有的词）。视频里这一步的说明会黄底标出、挂“★ 英语用词规律”；小黑板上写进黄框“重点”。`say` 里要把规律念出来，再举那个熟悉的例子。常见的几种：

| 规律 | 例子 |
|---|---|
| 词的核心意思不变，换了对象、场合，中文要换个说法，英语还是这个词（5.11，总表新规律） | produce 拿到前面来 → 生产、出示；play 玩 → 踢（球）、演奏（乐器） |
| 东西换了代，干的还是那件事，旧名字就接着用（5.11） | camera 照相机 → 摄像机；phone 电话 → 手机 |
| 作用、做法像什么，就借它的名字来叫（5.11） | memory 记忆力 → 内存；virus 病毒 → 电脑病毒 |
| 表示动作的词，也拿来叫做这件事用的东西 | transport 运 → 运输工具；cover 盖 → 盖子 |
| 表示动作的词，也拿来叫做这个动作做出来的东西 | invention 发明 → 发明出来的东西；building 建 → 建筑物 |
| 表示东西的词，也拿来说用这个东西做事 | hammer 锤子 → 用锤子敲；water 水 → 浇水 |
| 表示地方的词，也拿来叫在那儿的人 | school 学校 → 全校师生 |
| 具体的意思，慢慢用到抽象的事上 | grasp 抓住 → 理解；see 看见 → 明白 |
| 一个词的意思越用越宽（或越窄） | …… |

不在演变链里的规律（拼写、构词的习惯，比如“以 e 结尾的动词加 -ion 时去掉 e”），写在 prefs 的 `rules` 里，也会上小黑板。

### 身份和分工（`fengong`）、同义词辨析（`distinguish`）——6.0 起

**关系**（6.3，总表“词缀关系版”）：辨析那几句后面自动多一句“再看它们的关系：…”——总表这一组辨析最后“；关系：…”里讲本词缀的第一条，括号里的不念（“pre- 和 pro- 不是一个变出另一个，它们是拉丁语里两个同源的介词。”）。6.4 起这一句放在最后：有“为什么用 -ous 不用 -ful”的，先念那一句，再念关系（画面上关系在最下面）。
这一句长（二三十个字到五十来个字）；嫌长就在 plan.json 里把这一句删短，画面上的“关系”框照旧写全。读音拆分里元辅e 的解释念“元辅 e 结尾：e 不发音，让 u 读字母音……”。

**前缀辨析 / 后缀辨析**（6.2，总表“词缀身份辨析版”的词缀行）自动起草，一般不用改：第 1 句“再来辨析一下。同样和前面有关的，有这么几个。”（总说不是“同样…”开头的：“再来辨析一下。这几个都是同一个拉丁语前缀 a d。”）；
后面一条辨析一句，最多 3 条，本词缀那一条一定讲，括号里的例词念前两个，省略号念“什么”（“加在形容词前是不什么的”）；最后一句还是“为什么用 -ous，不用 -y 或 -ful？…”。句子数 = 1 + 讲的条数 + 1（有“为什么用…”时）。

**身份和分工**（词根；上一版总表的词缀）自动起草，一般不用改。讲法（用户：“不同写法分别是什么身份，怎么分工，这个一定要讲清楚”）：
1. 第一句讲身份。词根：“词根 duc 有几种写法，身份不一样。这里的 duct，是过去分词的样子。”词缀：“后缀 -ous 的身份：拉丁语来的形容词后缀，经法语进入英语……”，分工有总说的接一句“同样是把名词变成形容词的，有这么几个。”
   **6.1：词根是拉丁语动词的，接着一句讲三个样子的变化规律**（用户：“要写出来拉丁语原形，过去式，过去分词的变化规律”）：“拉丁语动词也有三个样子。过去式是 duc 加 s，c 和 s 合写成 x；过去分词是 duc 加 t。”
   引子只有一句（三个框上写着“原形、过去式、过去分词”，不再念一遍）；后面照总表“规律：”那句话念——括号里的字（拉丁语、英语的整词）不念，词根当单词念（6.17），-avi、-atus 这类词尾照词缀的念法（留着连字符）。
   没有单独过去式的动词引子换成“拉丁语动词本来有三个样子。”，接规律里的“这个动词只有被动的样子，没有单独的过去式；过去分词是 grad 加 t……”。
   这一句念的是表里的规律，改说法要改总表（维护技能的 dongbian_data.py）；只想这一个视频里换个说法，手改 plan.json 这一幕的第 2 句。规律里四个字母以上的词根照单词念（plaud、frag、stingu、quaer），还有个别不成词的字母串（ges），配音可能念不清，听的时候留意，念不清就在 plan.json 里把它拆成字母（g e s）。
2. 后面一条分工一句，括号里的例词念前两个：“duce 是动词原形的样子，当动词，说领这个动作，比如 produce、reduce。”说这一部分自己的那一条一定讲；词根最多讲 3 条、词缀 2 条，别的条只写在画面上（想多讲、少讲，手改 plan.json 这一幕的句子：第 1 句以后，第 k 句对画面上讲到的第 k 条）。
3. 总表有“为什么用 -ous 不用 -y / -ful：…”的，最后一句念它：“为什么用 -ous，不用 -y 或 -ful？-y、-ful 多接英语本族词；danger 是法语词，配同样经法语来的 -ous。”
6.17 起词缀都当单词念，留着连字符（-ous、-ful、un-、-able），synth.py 按词缀表念；“过去分词“被领出来的””念成“过去分词，被领出来的”。

**同义词辨析**：第一句提出问题（“produce 和 product，中文都可以说产品，区别在哪儿呢？”），每个词一句（“product 这个词，是产品，工厂造出来、拿去卖的东西，可以一件一件数。”——英文放句首、后面接“这个词”念得清楚），
最后一句讲逻辑（“它们的逻辑不一样：produce 用的是动词原形 duce，是把动词生产直接当名词用……”）。要求：
- 每个词那一句只讲它和别的词**不一样**的地方（概念、用法、可数不可数、正式不正式），不要把词典的意思再念一遍；
- 最后一句尽量从构词上讲（这一版的重点：身份不同，所以意思不同）；讲不出构词上的差别就写一句话记法（`tip`：“地里长的用 produce，工厂造的用 product”）；
- 自动拼出来的要看：挑的是不是学生最容易混的那一组（表里按中文意思对出来的同义词，有的并不常混）、每一句通不通。不合适就手写 `distinguish`，或者 `false`。

## 五、发音没听清怎么改

`synth.py` 合成每一句后，用语音识别（SenseVoice）听一遍：英文词没被认出来、或者中文一半以上对不上，就重念，最多 4 遍，留听得最清的一遍（同一句话每次合成会有一点不一样）。4 遍都不行的标“没听清”，按下表换说法：

| 情况 | 例子（38 号声音实测） | 改法 |
|---|---|---|
| 英文词打头、后面紧跟逗号和中文 | “transport，运输、运送”→“transranport 运输运送” | 换成冒号：“transport：运输、运送。” ✓ |
| 部分的英文打头 | “trans，是拉丁语前缀”→“ts 是拉丁语前缀” | 放到中文后面：“前缀是 trans，……”（“词根 port”会吞掉 t，“词根是 port”就清楚） |
| 短词根被听成中文 | “com 是一起”→“康是一起” | 拼字母：“c o m 是一起” |
| 常用词被吞 | “就有了 common，共同的”→“就有了他们共同的” | “就有了 common 这个词，意思是共同的” ✓ |
| 一串英文挤在一起 | “common，community，immune” | 拆成几句，每句一个词 |
| 英文词夹在中文里、后面紧跟“，就是…”（5.1 实测） | “也叫 product，就是产品”→“也叫 proud 就是产品”；“也叫 communications，常用复数”→ 英文整个没了；“所以，thermostat 就是恒温器”→“所以 thest 就是…” | 换成“也叫 product 这个词，意思是产品”“所以，thermostat 这个词，意思是恒温器” ✓ |
| 先试再改（5.1） | 一句一句改了再整段重跑很慢 | `python3 scripts/saytest.py product "说法一" "说法二" …`：每种说法合成一遍、识别一遍，打印 ✓ / ✗ 和听成了什么，挑 ✓ 的写进去。实测 product 的四种说法三种 ✓；thermostat 单独念也被听成“Trmosttathu”，放进英文句子里才认得出来——说明有些词是识别模型的毛病，配音本身是完整的 |
| 长单词跟在中文后面（5.1 实测） | “所以，thermostat 这个词…”→“所以 thest 这个词…”，同一个词放句首（title“thermostat：恒温器。”）就念得清 | 长单词放句首：“thermostat 这个词，现在的意思是…”；读音拆分“连起来”那句识别不了时写成普通单词并加进 lexicon |
| 例句里的数字、句末的长复数词（5.1 实测） | “to 22 degrees”→“to are, sure”；“…are modern communications.”→“…are modern.” | 数字写成英文（twenty-two degrees）；长词别放句末（Communications today are very fast.） |
| 同音字、m 和 n 听混 | “我坐公共交通”→“我做功共教通” | 多半是识别模型的毛病，画面上有字时可以 `--force` |

5.3 起讲解句是声音克隆（用户本人的声音），5.10 起整个视频只有两种声音：中文讲解是用户本人的声音；英文（单词、词根、词缀、读音拆分的音节块、整词、例句）都是 af_heart 美式女声；6.17 起单独的字母（e、加 s、答案是 D）也用用户本人的声音念字母名（规矩 43）。上面的改法照样管用，另外：

| 情况 | 改法 |
|---|---|
| 同一句话每次念得不一样（声音克隆的特点） | synth.py 会重念到听清为止（最多 4 遍），还不行退回 38 号；试说法时用 `saytest.py --times 3`，看 3 遍里几遍听得清，挑稳的说法 |
| 退回 38 号的句子音色不一样 | 日志最后列出“用了 38 号”的句子：按上表换个说法再跑，就能全用自己的声音 |
| 英文词夹在中文中间，声音克隆把词尾吞掉（5.4 实测：“就像 mouse 是老鼠”4 遍都念成 mo，退回了 38 号；5.5 起英文由英文声音念，一般遇不到了） | 英文词放句首：“mouse 本来是老鼠，用进电脑这一行，就成了鼠标。”（saytest 念 2 遍 2 遍都清楚） |
| 单独念的半个音节（读音拆分的 ca、me、ra） | 声音克隆念不了（太短会乱念），5.10 起用 af_heart 念，不用改；单独一个辅音的块（s、f、t）最难念自然，做新词时留意听 |
| 语气太平、太慢 | 参考录音的语气会被学过去：换一段讲课口吻的录音（voice_prep.py）；只是快慢可以调 plan.json 的 `zvSpeed` |

其他规矩：6.17 起英文分四种写法（SKILL.md 规矩 43）——单独的字母照写，字母之间空格（你本人的声音念字母名）；讲音的写 /音标/（/p/、/θ/）；前缀写 pro-、后缀写 -ion、词根照写（美式女声当单词念）；单词、句子照写；不要写配音会照念的符号（括号、省略号、引号、斜杠、箭头、等号）；英文单词照常写在中文句子里，不要自己拆句（5.5 起 synth.py 自动把英文拆出来用英文声音念，再接回去）。改完再跑一遍（run.py 发现 plan.json 变了会重新合成）。

## 音变的原因那一幕（6.6）
