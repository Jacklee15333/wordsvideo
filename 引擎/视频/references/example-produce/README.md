总表：拆分 `pro + duce(=duc)`；词根列“-duce：词根 duc 的另一种写法（同一个词根）。字母变化：duc → duce，…英语加不发音的 e。…；记：duc ∽ duck（鸭子）：…”。

- `plan.json`：起草出来的配音稿。`part1` 分三句（`marks: true`）：词根本身 / 在这里写成 duce + 字母怎么变 / 记法。
- `prefs.json`：
  - `partPics.p1`：词根卡片左边的画——鸭妈妈走在前面、三只小鸭跟着往右走（`go` + `anim: "ride"`），说到“领着走”出标签和箭头，说到“duck”出“duck 鸭子”。`icons.p1` 把拼起来那一格的小图标也换成 🦆。
  - `comboPic`、`flow[0].fig`：字面意思“领到前面来”还是这一家鸭子往前走。
  - `pics`：三个意思——生产（工厂 + 传送带，箱子一个个出来）、出示（手拿着车票递到检票亭前）、农产品（一篮蔬菜水果）；每个带例句和例句动画（`when` 用英文句子里的词：`produces`、`produce`、`fresh produce`）。
  - `flow`：五框。两步是用词规律，各配一个画出来的熟悉例子：
    - “词的核心意思不变，换了对象…”：play 玩 → ⚽ 踢（球）、🎻 演奏（乐器），再回到手拿车票“出示”；
    - “表示动作的词，也拿来叫这个动作做出来的东西”：invention ✍️ 发明这件事 → 💡 发明出来的东西，再回到一篮农产品。
    `from: 0`：出示、出产都直接从字面意思来。
  - `lexicon`：duce、duc 词典里没有，写上读音。
- `art/`：duck、duckling（也在 `references/characters/`）、factory、belt、ticket、hand、booth、field、sprout、basket。
