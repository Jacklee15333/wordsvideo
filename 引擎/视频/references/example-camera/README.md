# camera：基础词的标准样例（5.0 起；5.11 改成“说到哪个词出哪样东西”）

- `plan.json`：配音稿（起草自动生成：读音拆分的音素词 `lexicon`、演变一步几句的 `groups`）。
- `prefs.json`：画面设置。看这几处：
  - `originPic`：来历“拱顶的屋子”——拱顶屋子的插图，金线描出拱顶（`ray` + `on`），标签“拱顶”。
  - `pics`：两个意思都是主角特写（`studio` 背景、`s` 0.6～0.72、`shadow`）：照相机快门一沉 + 闪光 + 照片；摄像机屏幕里小狗在跑 + REC 红点闪。
  - `flow`：每一步一幅示意图 `fig`；`say` 拆成几句，`fig` 里的东西写 `when`——配音说到这个词才出来：
    - 暗室：说到“不透光”标“暗室：不透光”，说到“小孔”小孔亮，说到“屋外的景物”两道光线射进来，说到“倒着映”像出来（几何按小孔成像算）；
    - 暗箱 → 照相机：说到“越做越小”暗室缩小（`growWhen`），说到“盒子”换成木盒相机，说到“有了照相技术”相机挪开（`goWhen`）、照片出来；
    - 用词规律“东西换了代，干的还是那件事，旧名字就接着用”：规律的三个要点一个个出来；熟悉的例子 ☎️ phone 电话 → 📱 phone 手机；再回到照相机 → 摄像机。
      （5.0 这一步写的是“一个词用进某一行…”，例子 mouse → 鼠标，和 camera 不是一回事；总表“用词规律”轮换掉了。）
  - 例句动画：给小狗拍照（侧面相机、Click!、闪光、照片飞出）；门口的监控摄像头（房子正面铺满、光锥来回扫、红灯闪）。中文那一句说的时候各有一个标签出来（“照片”“监控摄像头”）。
  - `lexicon`：生词 obscura 的读音。
- `art/`：这一个词画的写实插图（svg）。做别的词时照这个精细程度画，用 `scripts/artsheet.py` 先看一遍。
