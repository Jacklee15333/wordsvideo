02

组合列里把重复的演变内容融合

2026-11-11
总表结构类

标签：总表结构 / 组合列 / 含义演变

还需要进行一下优化：

【构词逻辑】common（共同的）+ ic + ate（使…）=「使（东西）变成大家共有的」
→ 把自己知道的、拥有的「分」给别人，让它变成彼此共有的，消息就这样传开了 →（1520s）传达、传递（信息、感受）
→ 你传给我、我传给你 → 交流、沟通
→ 病也能从一个人「分」到另一个人身上 →（疾病）传染
→ 两个房间「共用」一条通道，彼此连着 →（房间之间）相通
【词性变化】-ate：变成动词。common + ic 合起来，加上 -ate，就成了一个动作（动词说的是「做什么」），所以 communicate 是交流、沟通 / 传达 / 传染
【演变】（1520s）把信息、感受传给别人 → 交流、沟通
【今义】交流、沟通；传达（communicate ideas 表达想法）；（疾病）传染；（房间之间）相通
【辨析】汉语「沟通」偏「双方相互理解」；communicate 的根本义是「传过去、让对方也拥有」，所以疾病也能「传」过去（communicable disease 传染病）

你看，「组合 → 现在的含义」这一列原本也有对单词含义演变的讲解，但是可能不太全。刚刚的做法只是简单地把内容从「各部分解释」转移到「组合 → 现在的含义」这一列，放在下面，两者并没有融合在一起。我现在希望能把这两部分的内容根据每部分的意思，讲相同含义演变的部分要融合在一起。

标签：总表结构 / 各部分解释 / 组合列

我发现我忽略了一个很重要的东西：你看表里面的内容 —— 拆分 / 各部分解释 / 组合 → 现在的含义，是分为这三列的。

  • 拆分：只进行拆分的动作
  • 各部分解释：只要对各部分进行解释就可以了
  • 组合 → 现在的含义：将各部分解释的含义进行逻辑组合，得到现在的各个含义

但是我昨天忽略了「组合 → 现在的含义」这一列，以为表里面没有组合的内容，结果在「各部分解释」里面增加了很多组合的内容。我现在希望把「各部分解释」里面进行组合的部分搬到「组合 → 现在的含义」这一列，这样「各部分解释」就只需要做对拆分后的各个部分进行解释就可以了。

「组合 → 现在的含义」负责对单词的逻辑、含义、用词规律这些进行处理。做视频的时候：拆分就看「拆分」这一列；各部分的解释就看「各部分解释」这一列；详细逻辑、用词规律就看「组合 → 现在的含义」这一列，这样就比较方便了。
