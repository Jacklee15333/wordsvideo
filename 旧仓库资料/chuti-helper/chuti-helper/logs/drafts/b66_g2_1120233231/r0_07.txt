@synonym
听|“Big”和“large”在句子里被说成什么词？|"Big" and "large" are synonyms.|同义词 / 反义词 / 同音词 / 多义词|are synonyms 说这两个词是同义词。
单|"Big" and "large" are ______.|synonyms / synonym / antonym / antonyms|主语是两个词，be 动词后用复数 synonyms。|
改|"Hot" and "cold" are synonyms.|synonyms → antonyms|hot 与 cold 意思相反，应该说 antonyms（反义词）。|
选|synonym、antonym|"Small" is the ______ of "big".|antonym|意思相反的词是 antonym，small 与 big 相反。|
完|你能给我一个“big”的同义词吗？|Can you give me a ______ of "big"?|synonym|a … of 中间要用单数名词 synonym。|
形|This book lists many ______ of each word. (synonym)|synonyms|many 后面接可数名词复数 synonyms。|变形
单|"That's ______ news — our team won the game!"|big / large / many / few|news 前用 big 不用 large，同义词并不能随意互换。|易混
@instal
听|新校长是什么时候就职的？|The new headmaster was installed last Monday.|上周一 / 上个月 / 昨天 / 下周一|was installed last Monday 说明是上周一就职的。
单|The new mayor ______ last Friday.|was installed / installed / is installed / installs|last Friday 表过去，市长是“被就职”的，用 was installed。|
改|A new judge were installed yesterday.|were → was|主语 a new judge 是单数，yesterday 表过去，用 was。|
选|instal、instals|Our school ______ a new headmaster every few years.|instals|主语 our school 是单数，every few years 表习惯，用三单 instals。|
完|我们将在五月让新校长就职。|We will ______ the new headmaster in May.|instal|will 后面接动词原形 instal。|
形|They are ______ the new system now. (instal)|installing|are … now 用现在分词，instal 要双写 l 再加 ing。|变形
单|He was installed ______ chairman last year.|as / for / to / with|be installed as + 职务，表示就任某职位。|短语
@install
听|爸爸在手机上做了什么？|My father installed a new app on my phone.|安装了一个新应用 / 买了一个新手机 / 删掉了一个应用 / 修好了手机|installed a new app 是给手机安装新应用。
单|The workers ______ the new machine last Monday.|installed / install / installs / installing|last Monday 表过去，用过去式 installed。|
改|The new app was install on my phone.|install → installed|was 后面要用过去分词 installed，构成被动语态。|
选|install、installation|The ______ of the new system took two hours.|installation|the … of 结构中要用名词 installation。|
完|你能帮我安装这个新游戏吗？|Can you help me ______ this new game?|install|help sb. do sth.，后面用动词原形 install。|
形|He is ______ a new app on his phone now. (install)|installing|is … now 用现在分词 installing。|变形
单|It took us an hour to ______ the new tent.|set up / install / fit / place|搭帐篷用 set up，install 指把设备固定安装好。|易混
