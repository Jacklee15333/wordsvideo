@bony
听|说话人不喜欢什么？|I don't like bony fish because it has too many bones.|刺多的鱼 / 新鲜的鱼 / 大鱼 / 冷冻的鱼|bony fish 指多骨、刺多的鱼。
单|This fish is very ______, so watch out for its bones.|bony / bone / bones / bonily|bony 是形容词“多骨的”，作表语；bone 是名词。|
改|The old man's hands are bony, and you can see every bones.|bones → bone|every 后面接单数名词 bone。|
选|bony、skinny|My little brother is tall and ______, but he eats a lot.|skinny|skinny 是口语里说人瘦；bony 指瘦到骨头都凸出来，不合“吃得很多”。|
形|This fish is ______ than that one. (bony)|bonier|than 提示比较级，辅音字母加 y 结尾要把 y 变 i 再加 er。|
完|他昨天摔断了一根腿骨。|He broke a ______ in his leg yesterday.|bone|腿骨是可数名词 bone，前面有 a 用单数。|词性转换
单|This is the ______ fish I have ever eaten.|boniest / bonier / bony / bonyest|ever 提示最高级，bony 的最高级是 boniest（y 变 i 加 est）。|变形
@function
听|心脏的主要功能是什么？|The main function of the heart is to pump blood.|把血液泵到全身 / 储存食物 / 帮助呼吸 / 控制体温|the function of the heart 指心脏的作用。
单|These machines have many useful ______.|functions / function / functional / functioning|many 后面接复数名词，function 的复数是 functions。|
选|function、use|We make good ______ of the library every day.|use|make use of 是“利用、使用”；function 指事物本身的作用。|
形|The chair is simple but very ______. (function)|functional|系动词 is 后面作表语要用形容词 functional。|
改|This machine has many function.|function → functions|many 后面接可数名词复数 functions。|
完|昨晚许多名人参加了这个典礼。|Many famous people came to the ______ last night.|function|表示“正式活动、典礼”用 function。|用法
单|This old machine is still ______; it works well.|functional / function / functions / functioning|still 后作表语、说“能正常运转的”要用形容词 functional。|词性转换
@functional
听|这个旧收音机怎么样？|This old radio is still functional after fifty years.|还能正常使用 / 已经坏了 / 太贵了 / 太重了|still functional 指“仍然能正常使用”。
单|The new kitchen is small but very ______.|functional / function / functions / functioning|but 后面与 small 并列，要用形容词 functional（实用的、好用的）。|
选|functional、function|Each button has its own ______ on this machine.|function|its own 后面要名词 function（功能）；functional 是形容词。|
形|Every part has an important ______ in the body. (functional)|function|an important 后面要名词 function（作用）。|
改|We should check the machine's functional first.|functional → function|所有格 machine's 后面要用名词 function。|
单|Her advice is always ______; we can really use it.|practical / functional / function / practice|真正可行、能派上用场的用 practical；functional 指“与功能有关的、能运转的”。|易混
完|这台机器有很多功能。|This machine has many useful ______.|functions|many 后面接可数名词复数 functions。|变形
